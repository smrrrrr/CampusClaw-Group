## MODIFIED Requirements

### Requirement: 文本分块

系统 MUST 将上传成功并解析为纯文本的材料先按 Markdown 标题及加粗子标签等锚点切分，再对超长段按段落合并或长度与重叠兜底切分为带序号的文本块（chunk）。系统 MUST 为每个分块记录其所属材料（material）、块序号（chunk_index）与内容。系统 MUST NOT 将整份材料作为单个检索单元直接提供给大模型。

#### Scenario: 解析材料生成多个分块

- **WHEN** 一份 PDF 材料被异步解析为纯文本后进入知识库索引流程
- **THEN** 系统按设定长度与重叠将该文本切分为多个带序号的文本块，每块记录所属材料、块序号与内容

#### Scenario: 短材料生成单个分块

- **WHEN** 一份材料的内容长度小于设定的分块长度
- **THEN** 系统生成一个包含全部文本的单个分块，块序号为 1

### Requirement: 向量化存储

系统 MUST 使用字符 bigram/trigram 的本地哈希生成 512 维向量表示，以 float32 BLOB 持久化；本期不是外部语义 embedding 模型，MUST NOT 承诺同义改写召回质量。向量 MUST 关联所属班级 class_id、所属材料与块序号。系统 MUST 支持在后续检索时按班级范围访问这些向量。

#### Scenario: 分块向量化并存储

- **WHEN** 文本块生成完成
- **THEN** 系统为该块生成向量表示，连同 class_id、material_id、chunk_index 一起持久化，供检索使用

#### Scenario: 向量化失败不阻塞上传

- **WHEN** 某文本块向量生成失败
- **THEN** 系统记录失败原因，该块相关材料标记为未索引，但不中断上传流程

### Requirement: 限定班级的知识库检索

学生提问时，系统 MUST 仅在其所在班级（class_id）的分块集合内，通过当前配置的关键词、向量或混合排序召回与问题最相关的 Top-K 个文本块，作为大模型上下文。系统 MUST NOT 检索其他班级的分块。检索场景（学生或教师）MUST 仍遵循班级数据隔离规则，越权访问 MUST 返回 403 Forbidden 并记录审计日志。

#### Scenario: 学生提问召回本班相关分块

- **WHEN** 学生 class_id=101 向 AI 解题助手提问
- **THEN** 系统仅检索班级 101 的分块，按当前检索模式返回 Top-K 个相关文本块作为上下文

#### Scenario: 检索严格限定本班范围

- **WHEN** 学生提问时存在其他班级（如 102）的分块与问题高度相关
- **THEN** 系统不召回班级 102 的分块，回答仅基于班级 101 的资料

#### Scenario: 无可用分块时降级

- **WHEN** 学生提问但本班没有任何已索引的可检索分块
- **THEN** 旧单次接口直接返回无资料提示；多轮会话仍携带已有历史和无新资料说明调用模型，引用列表为空，不能伪造来源

### Requirement: 跨章节检索预筛 (Cross-Chapter Prefilter)

在向量相似度排序之前，系统 MUST 对班级内的候选材料按标题与问题的字符二元组（bigram）重叠做一次轻量预筛，排除与问题无实质关键词共现、仅字面重叠但属于不同章节的材料（如 3D 空间几何问题排除"平面解析几何"材料），使这些材料不参与向量排序与召回。当预筛后无任何材料保留时（如班级只有"统练/期中/月考"等泛化标题材料），系统 MUST 回退为保留全部候选，避免检索结果为空。

#### Scenario: 跨章节无关材料被预筛排除

- **WHEN** 学生提问「空间中点到直线的距离公式」，本班既有"第一章 空间向量与立体几何"总结材料，又有"第二章 平面解析几何"总结材料
- **THEN** 系统在向量排序前按问题与标题的字符二元组重叠，将"平面解析几何"材料排除在候选之外，仅保留空间向量相关材料召回，其参考资料不出现解析几何材料

#### Scenario: 预筛无保留时回退全保留

- **WHEN** 预筛后没有任何材料与问题共享字符二元组（如班级仅含泛化标题的统练/月考材料，其标题不含问题关键词）
- **THEN** 系统回退为保留全部候选材料参与向量排序，保留候选继续检索；仍可能因绝对命中门槛而返回空结果

### Requirement: 关键字、向量与混合检索

系统 MUST 支持三种检索方式并默认采用混合检索：**关键字检索**（按问题词元与分块内容的字面重叠打分）、**向量检索**（余弦相似度）与**混合检索**（将关键字与向量两种排序通过 Reciprocal Rank Fusion（RRF）融合为最终排序）。检索行为 MUST 仍限定在本班范围并遵循班级数据隔离。混合检索为默认模式，可通过配置在 vector / keyword / hybrid 之间切换。

#### Scenario: 关键字检索返回字面命中的分块

- **WHEN** 配置为 keyword 模式检索某问题
- **THEN** 系统按问题词元（字符二元组）的 TF 与 IDF 加权得分排序，余弦分数可用于同分排序

#### Scenario: 向量检索按哈希向量相似度排序

- **WHEN** 配置为 vector 模式检索某问题
- **THEN** 系统按本地哈希向量余弦相似度排序；仍使用标题预筛和绝对词元命中门槛，不承诺纯语义召回

#### Scenario: 混合检索融合两路排序

- **WHEN** 采用默认 hybrid 模式检索
- **THEN** 系统同时计算向量相似度与关键字分数，对两路排序做 RRF 融合（得分 = Σ 1/(60+rank)），以融合分降序返回 Top-K，同时被两路命中的分块排名更靠前

### Requirement: 基于限定的被检索资料回答

系统 MUST 将召回且通过版本核对的实际文本块作为上下文，MUST NOT 提供整份未召回材料。所有角色提示词（含教师自定义和固定引导框架）MUST 追加统一引用约束：仅在当前片段直接支持相邻论断时引用，不将相关性当作支持证据；不伪造文件名、页码、链接或引号内原文。片段未含公式或结论时 MUST 如实说明依据不足；模型补充的常识、公式或自行计算 MUST 与讲义内容区分，MUST NOT 冒充讲义原文并挂来源。资料中的指令 MUST NOT 改变引用约束。

#### Scenario: 答案基于召回分块生成

- **WHEN** AI 生成回答
- **THEN** 检索上下文仅包含本班当前学科通过原文件版本核对的分块，回答使用统一引用约束；多轮会话可带去除旧助手引用编号的历史

#### Scenario: 无召回分块不臆造依据

- **WHEN** 本班没有与问题相关的分块被召回
- **THEN** 系统明示缺乏相关班级资料，不虚构引用或答案
