## Decisions

### 1. 身份与当前工作区分开

班主任身份由 `homeroom_class_id` 是否非空推导；`workspace` 只选择当前内容。班主任入口始终使用带班班级，任课班级由 `teaching_classes` 下拉选择。共用 hook 给教师主页、资料页和上传页生成链接，使返回、切班与菜单范围一致。

教师导航顺序为：班主任工作台（有身份才显示）、任课教学、教研中心、系统与统计。助手配置是主菜单项并紧邻审计上方，不再保留顶部“我的带班/任课教学”切换控件与右上角账号快捷切换。

### 2. 重置密码在后端判定

同一教师可以在任课页面浏览自己的带班班级，页面仍按任课模式隐藏重置操作。接口不依赖页面上下文：目标学生必须存在、角色为 student、已分班，且其班级等于教师 `homeroom_class_id`。任教列表不能替代班主任条件。初始密码恢复后设置强制改密。

### 3. 已有接口与演示区域分开记录

| 区域 | 已有真实能力 | 本期界面/待接入 |

| 教师助手 | 每班/学科/教师的提示词与 tutor_enabled、默认提示词读取、班级单科资料入口 | 其他技能开关、MCP；移除示例密钥和静态绑定清单 |

资料页的学科标签仅在返回列表的文件名、描述和标签中匹配，不表示已经新增材料 subject 字段或后端学科权限。助手配置仍是每班一份，不是每学科一份。学生技能徽标是静态展示，不能用于确认教师配置已同步。

### 5. 构建与静态资源

Windows 上构建前先停止自己启动的本项目 standalone 服务，避免其占用 .next 目录导致构建停滞。构建成功后复制 .next/static 至 .next/standalone/.next/static，若有 public 则一并复制，再运行 standalone/server.js。页面与引用 CSS 都必须返回成功且 CSS 内容类型正确。

本次会话已执行 TypeScript 检查、生产构建并确认 CSS 请求为 200。仅补齐静态资源不会让已启动的服务器自动重新扫描文件，故应在补齐后重启。此处记录已采用的本地启动流程，不宣称自动打包脚本已经实现。
