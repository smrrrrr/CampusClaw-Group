## MODIFIED Requirements

### Requirement: 助手对话保留真实会话能力

助手对话页 MUST 保留本人当前班级的会话列表、新对话、历史选择、删除、连续提问、流式回答和引用来源；回答 MUST 保留 Markdown 与 LaTeX 渲染。界面 MUST 展示学习助手标题、学科标签、技能状态区域和解题引导说明。

数学/语文/英语/物理/化学标签 MUST 实际切换科目，按本人班级读取该科任课教师配置与历史。解题引导状态 MUST 来自后端，作业批改及错题讲解 MUST 标为尚未接入。实际会话、提示词和技能行为 MUST 以 `agent-assistant` 后端契约为准，不能以静态状态文案作判断。

#### Scenario: 从助手页连续追问

- **WHEN** 学生在同一会话提交问题并继续追问
- **THEN** 使用现有会话与 SSE 接口，保留历史与来源，遵循每日限额及本人/本班隔离

#### Scenario: 查看回答来源

- **WHEN** 助手消息包含来源引用
- **THEN** 按 reference_id 显示文件名、块序号及真实分块摘录；有 file_sha256 时校验版本后打开原文，版本变化显示错误；旧无版本来源提示重新提问并禁用原文按钮，没有来源时不伪造引用
