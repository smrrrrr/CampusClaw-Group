## ADDED Requirements

### Requirement: 学生按科目切换教师助手

学生 MUST 能选择数学、语文、英语、物理和化学助手，URL 记录 subject，刷新后保留科目。GET /api/student/assistant-config MUST 只解析学生本班、所选学科且仍任教该班的教师，返回 teacher_id、teacher_name、configured 和真实 tutor_enabled，MUST NOT 向学生返回系统提示词或密钥。未配置时 MUST 明示使用默认助手且引导未开启，MUST NOT 显示虚假启用状态。

同班同学科多名教师均 MUST 能各自保存配置。新会话默认选择符合任教关系的最近保存配置；没有已保存配置时选择编号最小的该科任课教师。新会话 MUST 绑定 teacher_id，之后不因另一位同科教师保存而切换；任课关系失效时 MUST 返回 409 并要求新建会话。历史会话的配置读取 MUST 校验本人、班级与科目。

#### Scenario: 数学与物理配置各自生效

- **WHEN** 张老师配置本班数学助手，李老师配置本班物理助手，学生分别选择数学和物理
- **THEN** 分别应用对应教师提示词和引导开关，检索对应科目资料，历史列表互不混用

#### Scenario: 同科教师不覆盖彼此配置

- **WHEN** 同班两名数学教师分别保存配置
- **THEN** 两份配置独立保留，各教师只读取和编辑自己那份；已有会话仍使用绑定教师配置

#### Scenario: 切换科目时隔离异步状态

- **WHEN** 学生切换科目
- **THEN** 清除旧科目的消息和输入状态，加载新配置和历史后才允许发送，旧请求不得覆盖新科目状态，流式回答期间禁止切科

#### Scenario: 没有该科配置

- **WHEN** 学生选择尚未配置的科目
- **THEN** 展示默认助手提示，不虚构教师配置或已开启技能

## MODIFIED Requirements

### Requirement: 教师的可配置提示词

教师 MUST 能按任教班级和自己的学科自定义 AI 解题助手的系统提示词，并能在任意时刻保存与重新读取。系统 MUST 将配置持久化（class_id、subject、teacher_id 联合唯一，各教师独立），关闭解题引导时，教师留空提示词 MUST 回退到内置默认提示词；开启时 MUST 使用固定引导框架，忽略已保存的自定义提示词但不删除它。教师 MUST 只能配置其任教班级（`teaching_classes` 范围内），越权配置 MUST 返回 403 并记录审计日志。

#### Scenario: 教师保存某班自定义提示词

- **WHEN** 教师在任教班级（如 class_id=101）保存一份自定义系统提示词
- **THEN** 系统将其持久化到本人/该学科/该班级的 AgentConfig，学生在该班关闭解题引导后提问时使用该提示词；开启引导时保留配置但使用固定引导框架

#### Scenario: 留空回退默认提示词

- **WHEN** 教师关闭解题引导并清空某班级的自定义提示词，或该班从未保存过配置
- **THEN** 学生在该班提问时使用内置默认提示词，保留 LaTeX 定界符及直接表达要求，并追加统一引用真实性约束；依据不足时必须如实说明

#### Scenario: 配置非任教班级被拒绝

- **WHEN** 教师尝试保存或读取一个不在其 `teaching_classes` 内的班级配置
- **THEN** 系统返回 403 Forbidden 并记录审计日志

### Requirement: 「解题引导」技能开关

教师 MUST 能按班级开关「解题引导」技能。系统 MUST 将开关状态持久化。开启时 MUST 使用固定苏格拉底引导框架及格式/溯源规则，忽略教师自定义提示词；关闭时 MUST 使用自定义提示词或内置普通默认提示词，不附加引导规则。配置界面的初始开关值为 true；从未保存配置的班级学科实际使用普通默认提示词，教师保存后才应用开关，此边界 MUST 明确区分。系统 MUST 向教师提供技能文案预览。

#### Scenario: 开启解题引导技能

- **WHEN** 教师在班级开启解题引导技能后学生提问
- **THEN** 系统使用固定引导框架替代自定义提示词，AI 只给解题思路引导、不直接给出完全最终答案；自定义提示词仍可回读

#### Scenario: 关闭解题引导技能

- **WHEN** 教师在班级关闭解题引导技能后学生提问
- **THEN** 系统不追加技能文案，AI 按已保存自定义提示词或内置普通默认提示词作答

#### Scenario: 教师预览技能文案

- **WHEN** 教师编辑技能配置或点击技能文案查看
- **THEN** 系统返回"给思路不给答案"的技能文案内容供教师了解并确认

### Requirement: 多轮会话与上下文延续

学生 MUST 能创建多个会话并进入其中一个会话发起连续追问。同一会话内的历史消息（最近的若干轮）MUST 作为上下文在生成回答时传递给大模型，使追问能延续前文。会话 MUST 属于创建它的学生且绑定提问时的班级、学科与所选任课教师，读取/删除/追问会话 MUST 校验归属与班级一致；列表 MUST 按当前学科过滤，检索仅限该班该学科的已索引资料，非本人会话 MUST 返回 404 隐藏存在性，属于本人但班级不一致时 MUST 返回 403。

#### Scenario: 在会话内连续追问

- **WHEN** 学生在同一条个会话内连续发送"什么是向量夹角？""具体怎么算？"等追问
- **THEN** 系统把该会话前几轮的用户与 AI 消息一并作为上下文传给大模型，使"具体怎么算"能接着前文展开

#### Scenario: 新建与列出会话

- **WHEN** 学生点击"新对话"提交问题（或主动创建会话）
- **THEN** 系统创建一个绑定该学生与当前班级的新会话，并在会话列表中可见；问题作为首条消息、以其截断作会话标题

#### Scenario: 访问他人会话被拒绝

- **WHEN** 学生尝试读取或追问一个不属于本人，或属于其他班级的会话
- **THEN** 非本人或不存在时返回 404；本人会话班级不一致时返回 403 并记录审计日志

### Requirement: 独立的按班级助手配置界面

教师 MUST 从独立主菜单进入助手配置，并在页面内选择任教班级。界面 MUST 提供提示词编辑、填入默认提示词、保存提示词，以及解题引导开关；该开关 MUST 随保存提示词一并提交 `tutor_enabled`。切换配置班级 MUST 重新读取该班已保存的提示词和解题引导设置，配置按班级、学科及教师独立，MUST NOT 覆盖同班其他学科或其他教师配置。

#### Scenario: 保存提示词及解题引导

- **WHEN** 教师在 101 班编辑提示词和解题引导开关后点击保存提示词
- **THEN** 调用现有保存接口提交 `class_id=101`、`system_prompt` 与 `tutor_enabled`；学生该班后续提问使用后端保存结果

#### Scenario: 切班回读配置

- **WHEN** 教师在页面选择另一个任教班级
- **THEN** 加载目标班级配置，原班级保存值不被当前选择覆盖

### Requirement: 高级助手控件的预览边界

助手配置页 MUST 以提示词、AI 技能/助手参考资料和 MCP 区域组织内容。本期作业批改与错题讲解开关、技能上传/注册、MCP 添加/连接 MUST 仅作为界面预览；未接接口的按钮 MUST 提示尚未接入，MUST NOT 将本地状态当作服务端配置。

教师端 MUST NOT 提供示例 API Key、密钥显示按钮或真实密钥读取/编辑入口。运行密钥继续由服务端环境配置提供，MUST NOT 返回前端或进入代码仓库；本期不新增密钥配置状态接口，不用静态文字宣称服务已配置。只有已有提示词和 `tutor_enabled` 保存属于真实配置；学生页的解题引导徽标 MUST 从本班该科教师配置接口读取，MUST NOT 将作业批改/错题讲解的预览当作真实技能。

#### Scenario: 点击未接入的 MCP 或技能按钮

- **WHEN** 教师点击添加服务器或上传/注册技能
- **THEN** 页面提示对应接口尚未接入，不创建服务端资源或连接

#### Scenario: 打开教师助手配置

- **WHEN** 教师打开助手配置页
- **THEN** 不出现示例密钥或显示密钥按钮，现有提示词与解题引导保存流程保留

#### Scenario: 调整预览技能不产生真实批改配置

- **WHEN** 教师切换作业批改或错题讲解开关
- **THEN** 只改变当前页面预览状态，不承诺跨页面持久化或学生端生效


### Requirement: 自动检索班级学科参考资料

助手配置页 MUST 将静态绑定知识库列表替换为“助手参考资料（当前学科）”，说明助手自动检索所选班级已发布且完成索引的本科目学生资料，无需手动绑定。MUST NOT 展示虚构资料名称或“已绑定”状态。界面 MUST 明示教研组教师原稿不会直接用于学生问答，智能备课仍独立选择教研组素材。学生助手原有班级/科目过滤、索引版本核对与引用检索 MUST 保留。

#### Scenario: 查看当前班级参考资料

- **WHEN** 教师选择任教班级并点击“查看本班资料”
- **THEN** 进入 /materials，携带当前选择的 class_id 与 workspace=teaching，仅查看本科目资料；切换配置班级后入口同步更新

#### Scenario: 尚无任教班级

- **WHEN** 教师没有可选择的任教班级
- **THEN** 提示先选择任教班级，不提供无班级的参考资料跳转，也不虚构资料清单


### Requirement: 按学习进度自适应引导

解题引导开启时 MUST 使用固定系统框架并保留教师自定义提示词但不将其传入模型；本次更新 MUST NOT 改写教师已保存配置。框架 MUST 区分新题、概念疑问、局部纠错、卡住和已完成状态。概念/符号疑问可先简短解释，不强制反问；需要推进时每轮最多一个具体问题。已有作答 MUST 从当前步骤继续，不重复开场。MUST 接受自然语言、数值及学生主动输入的公式，不强制 LaTeX 输入。

学生卡住时 MUST 按知识点、下一步操作、局部示范逐级增加提示，每轮只推进一级，保留目标题关键计算/判断由学生完成；不得因“不会”或索要答案而直接代做完整题目。学生已给出答案时可核对，理由充分后总结结束，不无限追问。缺少题干/图示或可靠依据时先澄清，不猜测；禁止内部检索流程表述，不禁止正常数学连接词。公式格式和统一引用真实性约束继续生效。

以上为模型输入约束，MUST NOT 宣称输出已被程序保证为单问题、数学正确或绝不泄露答案；仍需通过样例评估模型行为。

#### Scenario: 概念与学生公式作答

- **WHEN** 学生询问概念或主动提交公式、计算过程
- **THEN** 先解释具体疑问或检查当前步骤，不要求改成文字，不重新询问已展示的思路

#### Scenario: 多次卡住与完成

- **WHEN** 学生表示不会或已经自行给出最终答案及理由
- **THEN** 前者依据已给提示只提升一级帮助，后者核对并在理由充分时总结结束，不代算整题也不无休止追问

### Requirement: 引导短追问重新检索依据

已保存解题引导开启的多轮会话，对明确的短追问词、数值或简短公式作答，MUST 在最近 12 条历史消息中查找最近独立用户题目，结合原始本轮消息组织检索查询，仍限定当前会话班级和科目，逐轮核对原文件 SHA 和真实分块。不直接复用历史 citations 或编号，不把模型历史回答作为检索题目来源。独立新问题及非引导模式 MUST 使用当前问题检索；没有合适题目或题目超过 2000 字符时保留当前查询，不截断题目条件。本轮用户消息原文与计数/历史保存方式保持。

短追问识别本期使用有限词表及数值/简短公式规则，不宣称理解任意省略表达；历史超出最近 6 轮时可能需要学生重述题目。

#### Scenario: 学生只回复数字或不会

- **WHEN** 同一引导会话已有完整题目，学生回复“2”“x=2”“不会”或“为什么”
- **THEN** 结合最近用户题目重新检索当前班级当前科目资料，原始作答仍作为当前消息传给模型，引用采用本轮核对结果

#### Scenario: 换题或无题目锚点

- **WHEN** 学生提交独立新题，或历史没有适用用户题目
- **THEN** 不拼接不相关旧题，只使用本轮消息检索，资料不足时如实说明，不伪造出处
