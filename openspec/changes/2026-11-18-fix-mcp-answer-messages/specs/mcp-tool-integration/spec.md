## ADDED Requirements

### Requirement: 工具消息配对及最终回答

服务端在后续工具决策中 MUST 按调用 ID 配对模型的助手调用消息与所有对应工具结果，包括拒绝和失败。最终流式回答 MUST 使用原始对话和通过安全检查的工具数据，不携带决策中的临时协议消息。模型调用失败时 MUST 继续使用既有降级提示，并且运行日志不得记录资料正文、提示词、工具正文或密钥。

#### Scenario: 完成工具调用后继续回答

- **WHEN** 模型提出公式提示调用且 MCP 返回通过安全检查的结果
- **THEN** 下一轮模型决策收到完整配对的消息，最终流式请求在用户消息的数据段收到工具提示，并正常完成回答

#### Scenario: 拒绝或失败后继续回答

- **WHEN** 模型提出的工具调用被拒绝，或工具执行失败
- **THEN** 后续决策收到对应调用的失败结果，最终流式请求仍可依据已检索资料作答且不包含被拒绝或失败的工具正文
