## Purpose

为 CampusClaw 的 AI 解题助手引入限定班级范围的知识库检索与内容溯源（RAG），使 AI 回答仅基于与本班问题最相关的资料片段并标注引用来源，取代当前"整份拼接全部已索引材料作为上下文"的做法。

## ADDED Requirements

### Requirement: 文本分块

系统 MUST 将上传成功并解析为纯文本的材料先按 Markdown 标题及加粗子标签等锚点切分，再对超长段按段落合并或长度与重叠兜底切分为带序号的文本块（chunk）。系统 MUST 为每个分块记录其所属材料（material）、块序号（chunk_index）与内容。系统 MUST NOT 将整份材料作为单个检索单元直接提供给大模型。

#### Scenario: 解析材料生成多个分块

- **WHEN** 一份 PDF 材料被异步解析为纯文本后进入知识库索引流程
- **THEN** 系统按设定长度与重叠将该文本切分为多个带序号的文本块，每块记录所属材料、块序号与内容

#### Scenario: 短材料生成单个分块

- **WHEN** 一份材料的内容长度小于设定的分块长度
- **THEN** 系统生成一个包含全部文本的单个分块，块序号为 1

### Requirement: 向量化存储

系统 MUST 使用字符 bigram/trigram 的本地哈希生成 512 维向量表示，以 float32 BLOB 持久化；本期不是外部语义 embedding 模型，MUST NOT 承诺同义改写召回质量。向量 MUST 关联所属班级 class_id、所属材料与块序号。系统 MUST 支持在后续检索时按班级范围访问这些向量。

#### Scenario: 分块向量化并存储

- **WHEN** 文本块生成完成
- **THEN** 系统为该块生成向量表示，连同 class_id、material_id、chunk_index 一起持久化，供检索使用

#### Scenario: 向量化失败不阻塞上传

- **WHEN** 某文本块向量生成失败
- **THEN** 系统记录失败原因，该块相关材料标记为未索引，但不中断上传流程

### Requirement: 限定班级的知识库检索

学生提问时，系统 MUST 仅在其所在班级（class_id）的分块集合内，通过当前配置的关键词、向量或混合排序召回与问题最相关的 Top-K 个文本块，作为大模型上下文。系统 MUST NOT 检索其他班级的分块。检索场景（学生或教师）MUST 仍遵循班级数据隔离规则，越权访问 MUST 返回 403 Forbidden 并记录审计日志。

#### Scenario: 学生提问召回本班相关分块

- **WHEN** 学生 class_id=101 向 AI 解题助手提问
- **THEN** 系统仅检索班级 101 的分块，按当前检索模式返回 Top-K 个相关文本块作为上下文

#### Scenario: 检索严格限定本班范围

- **WHEN** 学生提问时存在其他班级（如 102）的分块与问题高度相关
- **THEN** 系统不召回班级 102 的分块，回答仅基于班级 101 的资料

#### Scenario: 无可用分块时降级

- **WHEN** 学生提问但本班没有任何已索引的可检索分块
- **THEN** 旧单次接口直接返回无资料提示；多轮会话仍携带已有历史和无新资料说明调用模型，引用列表为空，不能伪造来源

### Requirement: 跨章节检索预筛 (Cross-Chapter Prefilter)

在向量相似度排序之前，系统 MUST 对班级内的候选材料按标题与问题的字符二元组（bigram）重叠做一次轻量预筛，排除与问题无实质关键词共现、仅字面重叠但属于不同章节的材料（如 3D 空间几何问题排除"平面解析几何"材料），使这些材料不参与向量排序与召回。当预筛后无任何材料保留时（如班级只有"统练/期中/月考"等泛化标题材料），系统 MUST 回退为保留全部候选，避免检索结果为空。

#### Scenario: 跨章节无关材料被预筛排除

- **WHEN** 学生提问「空间中点到直线的距离公式」，本班既有"第一章 空间向量与立体几何"总结材料，又有"第二章 平面解析几何"总结材料
- **THEN** 系统在向量排序前按问题与标题的字符二元组重叠，将"平面解析几何"材料排除在候选之外，仅保留空间向量相关材料召回，其参考资料不出现解析几何材料

#### Scenario: 预筛无保留时回退全保留

- **WHEN** 预筛后没有任何材料与问题共享字符二元组（如班级仅含泛化标题的统练/月考材料，其标题不含问题关键词）
- **THEN** 系统回退为保留全部候选材料参与向量排序，保留候选继续检索；仍可能因绝对命中门槛而返回空结果

### Requirement: 关键字、向量与混合检索

系统 MUST 支持三种检索方式并默认采用混合检索：**关键字检索**（按问题词元与分块内容的字面重叠打分）、**向量检索**（余弦相似度）与**混合检索**（将关键字与向量两种排序通过 Reciprocal Rank Fusion（RRF）融合为最终排序）。检索行为 MUST 仍限定在本班范围并遵循班级数据隔离。混合检索为默认模式，可通过配置在 vector / keyword / hybrid 之间切换。

#### Scenario: 关键字检索返回字面命中的分块

- **WHEN** 配置为 keyword 模式检索某问题
- **THEN** 系统按问题词元（字符二元组）的 TF 与 IDF 加权得分排序，余弦分数可用于同分排序

#### Scenario: 向量检索按哈希向量相似度排序

- **WHEN** 配置为 vector 模式检索某问题
- **THEN** 系统按本地哈希向量余弦相似度排序；仍使用标题预筛和绝对词元命中门槛，不承诺纯语义召回

#### Scenario: 混合检索融合两路排序

- **WHEN** 采用默认 hybrid 模式检索
- **THEN** 系统同时计算向量相似度与关键字分数，对两路排序做 RRF 融合（得分 = Σ 1/(60+rank)），以融合分降序返回 Top-K，同时被两路命中的分块排名更靠前

### Requirement: 内容溯源

AI 回答 MUST 只携带正文实际使用的本轮来源编号，来源包含 reference_id、material_id、实际文件名、chunk_index、逐字原文 excerpt 和索引文件的 SHA-256。系统 MUST 从本班当前学科实际检索到的数据库分块生成引用，MUST NOT 让模型编写摘录或把全部候选都当成已引用来源。只有索引时记录的文件指纹与当前原文件一致的材料才能成为回答来源；缺少指纹、文件缺失或版本变化 MUST 排除并等待教师重新索引。

完成回答时 MUST 移除不存在于本轮候选中的数字引用编号并提示相关结论尚未核实，移除模型为数字引用附加的自拟链接；保留有效编号原值，不因只引用部分候选而重编号。以上校验保证来源身份、摘录和文件版本对应，MUST NOT 被描述为逐条论断已经通过自动语义验证。

#### Scenario: 回答标注引用来源

- **WHEN** AI 基于本班的若干文本块生成回答
- **THEN** 回答仅携带实际使用的有效来源，前端按原 reference_id 展示文件名、块序号和数据库真实分块全文

#### Scenario: 引用来源与检索一致

- **WHEN** 前端渲染回答的参考资料列表
- **THEN** 每项追溯到本班当前学科被召回的实际分块，excerpt 与分块逐字一致，文件指纹与索引记录一致

#### Scenario: 无效编号与未使用候选

- **WHEN** 本轮只有 [1]、[2]、[3] 候选，模型正文使用 [3] 和杜撰的 [99]
- **THEN** 最终来源列表仅保留编号 3，正文移除 [99] 并提示未核实，不添加未使用的 1、2，也不将 3 改为 1

#### Scenario: 文件变更或历史索引无版本

- **WHEN** 原文件已变化、丢失或索引未记录 source_sha256
- **THEN** 该材料不成为本轮引用候选，教师重新索引并成功记录当前指纹后才恢复可引用状态

### Requirement: 基于限定的被检索资料回答

系统 MUST 将召回且通过版本核对的实际文本块作为上下文，MUST NOT 提供整份未召回材料。所有角色提示词（含教师自定义和固定引导框架）MUST 追加统一引用约束：仅在当前片段直接支持相邻论断时引用，不将相关性当作支持证据；不伪造文件名、页码、链接或引号内原文。片段未含公式或结论时 MUST 如实说明依据不足；模型补充的常识、公式或自行计算 MUST 与讲义内容区分，MUST NOT 冒充讲义原文并挂来源。资料中的指令 MUST NOT 改变引用约束。

#### Scenario: 答案基于召回分块生成

- **WHEN** AI 生成回答
- **THEN** 检索上下文仅包含本班当前学科通过原文件版本核对的分块，回答使用统一引用约束；多轮会话可带去除旧助手引用编号的历史

#### Scenario: 无召回分块不臆造依据

- **WHEN** 本班没有与问题相关的分块被召回
- **THEN** 系统明示缺乏相关班级资料，不虚构引用或答案

### Requirement: 上传材料的索引流程扩展

上传成功的材料被异步解析为纯文本后，系统 MUST 按上述「文本分块」「向量化存储」要求将其切分为带序号的文本块并向量化，作为 rag-search 的可检索单元。仅当解析、分块与向量化全部成功时，系统 MUST 将 Material 表中 is_indexed 标记为 true。解析或分块向量化任一失败时，系统 MUST 将该材料 is_indexed 保持为 false，并 MUST NOT 让该材料的任何分块被 AI 检索。

#### Scenario: 上传成功后异步解析并分块向量化

- **WHEN** 教师上传一份 PDF 资料成功，经异步索引流程提取为纯文本后
- **THEN** 系统将文本切分为带序号的文本块、逐块生成向量存储，并标记该材料 is_indexed=true，使其分块可被 AI 解题助手检索

#### Scenario: 解析成功但向量化失败保持未索引

- **WHEN** 材料文本解析成功，但其分块向量生成失败（如 embedding 生成异常）
- **THEN** 系统将该材料 is_indexed 保持为 false，记录失败原因，该材料任何分块不被 AI 检索

### Requirement: AI 回答的 Markdown 与公式渲染

学生端 AI 解题助手 MUST 将大模型返回的回答以 Markdown 富文本方式渲染，支持标题、加粗、有序/无序列表等排版。回答中的 LaTeX 数学公式 MUST 通过 KaTeX 渲染为可视化的数学符号，而非展示 LaTeX 源码。公式定界符 MUST 采用 remark-math 支持的形式：行内公式用 `$...$`，独立公式用 `$$...$$`（独占一行）包裹——不得使用 `\(...\)`/`\[...\]`（remark-math 不识别，会导致公式源码原样透传）。系统 MUST NOT 以纯文本方式直接输出未渲染的 Markdown/LaTeX 源码。

#### Scenario: 公式渲染为数学符号

- **WHEN** AI 返回含 LaTeX 公式（如 `$$...$$` 包裹的 `\frac{\mathbf{a}\cdot\mathbf{b}}{|\mathbf{a}|\,|\mathbf{b}|}`）的数学解答
- **THEN** 前端用 KaTeX 将公式渲染为真正的数学符号，学生看到分式/公式排版而非源码

#### Scenario: 支持 Markdown 列表与加粗

- **WHEN** AI 回答包含步骤编号与加粗关键词（如 `**第一步**`）
- **THEN** 前端按 Markdown 规范渲染为有序列表与加粗文本

#### Scenario: 独立公式居中美化与长公式横向滚动

- **WHEN** AI 回答包含 `$$...$$` 独立公式块
- **THEN** 前端将独立公式块居中展示、浅灰底圆角、字号略放大，长公式横向滚动不截断

### Requirement: 回答不包含检索过程元话语

AI 解题助手 MUST 避免“资料检索”“召回”“按标准形式给出”等内部过程和过渡性元话语，直接解释知识或引导解题。该表达要求 MUST NOT 压过引用真实性：缺少公式或结论依据时 MUST 明确说明“未在本班资料中找到依据”，MUST NOT 为了省略说明而重建公式并挂上讲义引用。

#### Scenario: 资料未含公式本体时说明依据不足

- **WHEN** 班级资料提到某公式知识点但召回文本未包含公式表述
- **THEN** 提示词要求如实说明缺少依据；若提供一般公式，区分其与讲义原文且不给没有直接支持的来源编号

#### Scenario: 用户直接询问教材标准公式

- **WHEN** 学生直接询问教材中的标准数学/物理恒等式
- **THEN** 有直接依据时以 LaTeX 输出并标注有效来源；没有直接依据时如实说明，不伪称公式来自讲义

### Requirement: 回答正文与参考资料分离展示

AI 解题助手 MUST 将「回答正文」与「参考资料索引」渲染为两个视觉独立的区域：回答卡片展示大模型的解题文本；参考资料卡片独立于回答卡片之外展示被引用资料的出处与命中原文。参考资料 MUST NOT 内嵌在回答正文区域内部。

#### Scenario: 回答与参考资料独立成卡

- **WHEN** AI 返回回答文本与引用来源列表（citations）
- **THEN** 前端将回答正文渲染在回答卡片中，将参考资料渲染在独立于回答卡片的参考资料卡片中，两者视觉可区分

#### Scenario: 无引用时仅显示回答

- **WHEN** 本班无相关分块被召回或回答不携带任何引用来源
- **THEN** 前端只展示回答正文，不渲染空的参考资料卡片

#### Scenario: 命中可标注出处并回溯到原文

- **WHEN** AI 返回引用来源列表（citations），前端渲染参考资料卡片
- **THEN** 卡片按 reference_id 标注文件名与块序号，展示数据库真实分块，并以 file_sha256 请求原文；版本不一致时拒绝打开并提示重新检索，历史无版本来源禁止直接打开并提示重新提问

#### Scenario: 引用摘录保留真实分块

- **WHEN** 某个命中的分块同时包含「知识点讲解」与【即学即练】练习题的题干/选项，且题干与问题的字面重叠更靠前
- **THEN** 引用 excerpt 保留整个真实命中分块，不用生成摘要或改写替代原文，用户可对照完整片段核对是否支持回答

#### Scenario: 多命中逐条展示保留溯源

- **WHEN** 同一份材料有多段分块被召回，citations 中含多个同材料不同 chunk_index 的条目
- **THEN** 前端按命中逐条展示（每条含出处、块序号与各自原文片段），不因文件名相同而合并丢失溯源粒度和原文定位能力


### Requirement: 数值题公式检索与原文保持

系统 MUST 降低题干中独立数值和纯数字/标点词元的检索噪声，保留夹角、余弦等知识点词及字母相关词元；数字与字母/汉字连写时不按独立数值处理。向量查询使用去除独立数值后的文本，已有存储向量不改写。关键字排序 MUST 让没有标题的后续分块继承同一材料最近的真实 Markdown 标题作为检索上下文；块顺序按 material_id/chunk_index，遇到新标题更新，不跨材料继承。

标题只用于候选打分，返回引用摘录 MUST 仍是原始数据库分块全文，不将继承标题拼装后伪称原文。班级、学科、索引、原文件 SHA 及实际引用编号校验保持。检索排序改进不等于自动语义证明，MUST NOT 将所有命中候选都作为实际引用。

#### Scenario: 坐标题检索夹角余弦公式

- **WHEN** 学生题干含两组数值坐标并要求计算夹角余弦
- **THEN** 降低重复坐标数字的影响，优先召回含相关公式的片段，公式与标题分块时仍可依据章节标题召回；返回原文摘录与指纹

#### Scenario: 无关或变更资料

- **WHEN** 没有相关知识片段，或候选原文件已改变
- **THEN** 仍可返回无有效引用，不通过补编号或修改原文伪造出处
