## ADDED Requirements

### Requirement: 教师资料先导入学科组

教师 MUST 在 /teacher/library 导入带答案的教师版，支持 UTF-8 Markdown 或恰好含一份 Markdown、配图 PNG/JPG 和可选来源 JSON 的 ZIP。科目 MUST 来自当前数据库教师身份，不由上传参数决定；导入 MUST 不绑定班级、不新增学生 Material、不自动发布。资料包 MUST 限制 100 个文件及解压总量 50MB，拒绝重复路径、符号链接、越界路径、伪造配图和缺图；来源 JSON 不发布给学生。

#### Scenario: 导入完善版图文资料包

- **WHEN** 数学教师导入含教师版 Markdown 和 6 张原图的 ZIP
- **THEN** 资料进入数学教研组，保存原文及图像指纹，建立独立 ResearchChunk 索引，班级学生列表不新增资料

#### Scenario: 图片没有随 Markdown 导入

- **WHEN** 单独上传的 Markdown 引用了本地配图但未提供对应文件
- **THEN** 返回 400，提示将正文与配图一起打包，不产生缺图资料记录

### Requirement: 组内教师共享与学生隔离

组内资料列表、原稿、配图及学生版预览 MUST 仅供该学科教师访问，同科教师可共享使用，其他学科及学生 MUST 返回 403。组内原稿 MUST 记录来源 SHA-256，读取时核对当前文件；版本变化或丢失返回 409。重复导入同一学科的相同正文及相同配图版本 MUST 复用已有记录。学生检索 MUST NOT 查询 ResearchMaterial 或 ResearchChunk。

#### Scenario: 同科同事选用素材

- **WHEN** 另一名数学教师打开数学教研组资料
- **THEN** 可查看原稿及配图，后续只能选择本人任教班级发布学生版

#### Scenario: 学生直接猜测教师原稿地址

- **WHEN** 学生请求教师资料详情、预览生成或组内配图接口
- **THEN** 后端返回 403，不能借用学生所属班级访问教师原稿

### Requirement: 学生版题干提取与教师核对

学生版预览 MUST 采用确定的分区提取，保留明确的核心知识点区域、例题标题、题干、选项和题干所需配图，移除答案、解答、解法及后续教师解析、备课建议和来源管理附录。无法识别明确题干边界时 MUST 返回 422 并提示整理，MUST NOT 将完整教师版当作学生版。界面 MUST 支持编辑和预览，并要求教师确认正文及图片不含答案后发布；不得宣称能自动识别任意格式或配图中的答案。

#### Scenario: 现有结构化讲义生成学生版

- **WHEN** 教师选择含“### 例题 / **题干** / **答案**”的资料并生成预览
- **THEN** 得到保留题目和必要配图的学生正文，教师原稿保持不变，生成步骤本身不向班级发布

#### Scenario: 编辑后重新核对

- **WHEN** 教师修改学生版正文
- **THEN** 确认勾选状态清除，教师重新核对后才能发布；刷新前未发布修改仅留在当前页面

### Requirement: 学生版按任教班级独立发布

教师 MUST 在组内选择一份资料、核对学生版并选择一个或多个任教班级发布。后端 MUST 以当前数据库任教关系验证全部目标班级，任一越权则整批拒绝。缺少核对确认、明显答案/解析标记、教师原文链接、外部链接或未导入配图 MUST 被拒绝。成功时 MUST 为各班独立创建仅含学生正文和实际使用配图的 Material 与索引，并记录 MaterialPublication 来源关系；教师原稿及未使用教师解析配图 MUST NOT 被复制到学生资料。

#### Scenario: 发布学生讲义到两个任教班级

- **WHEN** 教师确认学生版并选择本人任教的 101、102 班
- **THEN** 两班各有独立学生稿及配图、索引和发布记录，教师版仍只在组内可见

#### Scenario: 越权班级混入发布批次

- **WHEN** 教师提交一批含非任教班级的目标
- **THEN** 返回 403，整批不创建任何班级资料

### Requirement: 发布时生成知识点标签

学生版发布 MUST 根据文件名和一级标题优先提取当前学科词表中的知识点名称，没有匹配时再使用知识点标题或正文中多次出现的明确术语，最多三个知识点；MUST NOT 仅凭单次无关提及或其他学科词表猜测标签。标签 MUST 同时保留学科和学生版身份并避免重复；未识别到知识点时只保留已有基础标签。当前使用确定性术语规则，不是模型语义分类。

#### Scenario: 立体几何章节带知识点标签

- **WHEN** 数学教师发布“第一章 空间立体几何”学生版，一级标题为“空间向量与立体几何”
- **THEN** 班级资料标签为“数学、立体几何、学生版”，不重复添加本章下属的空间向量标签

#### Scenario: 标题未包含已知知识点

- **WHEN** 文件名及标题均为泛化名称且没有可确认的知识点术语
- **THEN** 不虚构知识点，仍保留学科与学生版标签

### Requirement: 班级配图与图文包受权访问

学生版配图和图文包接口 MUST 校验所属 Material 的班级权限，配图以保存的 SHA-256 核对原文件。学生只能访问本班已发布配图与图文包；教师组内配图仍独立鉴权。前端 MUST 通过 Authorization 请求图片并使用临时对象地址显示，MUST NOT 将令牌写入图片 URL。图文包 MUST 仅含学生 Markdown 和实际使用原图，不含教师原稿或来源 JSON。

#### Scenario: 学生预览和下载有图讲义

- **WHEN** 学生打开本班学生版 Markdown 预览并点击下载图文包
- **THEN** 正文、公式和配图正常读取，ZIP 包保留相对图片路径；其他班请求配图和包返回 403

#### Scenario: 删除班级讲义

- **WHEN** 教师删除已发布的班级学生版
- **THEN** 清理班级正文、索引、配图及发布关系，组内教师原稿保持可用

### Requirement: 学生讲义打印与另存 PDF

前端 MUST 在本班 MD/TXT 讲义预览与教研组学生版预览提供“打印／另存为 PDF”，使用浏览器打印能力，不新增服务端 PDF 转换接口。打印稿 MUST 只包含当前讲义渲染正文、公式及配图，不包含导航、编辑器、发布表单、发布记录或教师原稿。打印前 MUST 等待配图解码及公式字体加载；配图失败或等待超时 MUST 提示重试，不输出缺图稿。打印稿 MUST 使用 A4、16mm 页边距及图片宽度限制，并提供基础分页规则。用户自行在浏览器窗口选择保存为 PDF 或打印；本期不保证复杂题目跨页时的精细排版。

#### Scenario: 学生保存图文讲义

- **WHEN** 学生预览有权限的本班 MD 讲义并点击“打印／另存为 PDF”
- **THEN** 加载完成后打开浏览器打印窗口，打印稿包含正文、数学公式和已授权配图，不包含应用导航和按钮

#### Scenario: 教师打印未发布的学生预览

- **WHEN** 教师在教研组资料生成学生稿并点击学生版预览旁的打印按钮
- **THEN** 只复制学生稿渲染内容，不混入教师原稿、编辑器或发布记录，且不触发班级发布

#### Scenario: 配图尚未就绪

- **WHEN** 配图请求失败、不能解码或加载超时
- **THEN** 提示重试，不以缺图状态继续打印

### Requirement: 原班级直传入口阻止明显教师版

单科资料发布直传入口 MUST 明示用于学生资料并提供组内资料入口。后端 MUST 拒绝文件名明确带教师版/教师用/参考答案的资料，以及 Markdown/TXT 内有明确答案解析标记或教师备课标识的内容，并提示走组内预览流程。本期检测为显式标记规则，MUST NOT 宣称是对所有文档及图片的答案语义检测。

#### Scenario: 完整教师 Markdown 误传班级

- **WHEN** 教师通过旧上传接口提交带答案、解析的完善版 Markdown
- **THEN** 返回 400 并提示先导入教研组资料，不新增班级文件或索引

### Requirement: 组内共享教案查阅与复用

组内列表 MUST 可按全部资料、教师素材、共享教案筛选，标记共享定稿版本。共享教案 MUST 可查看完整教师正文、配图及保存的原始出处摘录，并支持浏览器打印／另存 PDF 和下载教师图文包。包内正文及图片 MUST 验证保存指纹并遵循同科权限。组内教师可将共享教案选为新备课素材，MUST NOT 获得作者私人原稿的编辑权限；再次组织 AI 上下文时 MUST 去除旧稿内的 S编号再按新来源分配，保留原始摘录不变。

共享教案 MUST 禁止通过旧讲义确定性去答案预览及直接发布接口交给学生；界面引导在智能备课中选用、定稿、生成并人工核对学生稿后再分班发布。完整教师共享内容 MUST NOT 进入学生检索。

#### Scenario: 同科同事复用共享教案

- **WHEN** 同科教师在教研组资料筛选共享教案并选择使用此教案备课
- **THEN** 智能备课页面预选对应素材，后续生成新的本人私有教案，不修改原共享稿

#### Scenario: 下载教师图文包

- **WHEN** 有权限教师下载组内教师图文包
- **THEN** 包含经过指纹核对的教师 Markdown 与原图并保持相对链接，学生及其他学科请求返回 403

#### Scenario: 绕过学生稿制作

- **WHEN** 对共享教案请求旧学生版预览或旧班级发布接口
- **THEN** 拒绝并提示走智能备课学生稿制作流程，不复制完整教师教案到班级
