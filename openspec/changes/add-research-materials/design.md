# 设计

ResearchMaterial 保存 subject、教师原文件、正文、指纹及图片清单；ResearchChunk 单独保存组内分块向量，不进入学生 retrieve_top_k。当前学科来自数据库教师身份。教师原稿不可原位编辑，同一科目下正文及配图完全一致时复用导入记录。

按知识点区域及明确例题/题干/答案边界提取学生稿，不调用模型猜测答案位置。教师可编辑学生稿，发布前勾选核对正文及配图，后端重新拦截明显答案和不受管理链接。学生编辑稿发布前只保留页面状态；未知排版返回 422，图片答案仍需人工核对。

MaterialPublication 记录组内来源、教师和班级成品；发布各班独立 student.md 与实际使用的 MaterialAsset，沿用原班级索引流程。任何目标班级不在数据库当前任教关系内时整批拒绝。班级学生稿删除同时清理发布关系及配图，原教师资料保留。

教师原图与学生成品原图分别走鉴权接口，校验文件指纹，前端通过带 Authorization 的请求创建 Blob 地址显示。学生图文 ZIP 只打包学生正文及使用图片。普通 Markdown 文件下载仍是正文，图文包入口位于预览界面。

上传包最多 100 文件、展开 50MB，限制路径、链接和文件类型。原 MD 附带来源 JSON 仅用于本地核对，不随学生版发布。组内资料新表自动创建，部署前 SQLite 在线备份，数据与个人项目 8080 隔离。
