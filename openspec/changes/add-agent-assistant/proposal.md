## Why

原单次问答无法连续追问，也无法根据任课教师和班级配置教学方式。本变更及后续学科助手完善已实现可配置、多轮、带解题引导与来源核对的学生助手。本文于 2026-10-20 对照当前实现更新，替代早期“每班唯一配置”和子女切换描述。

## What Changes

- 配置按 class_id、subject、teacher_id 联合唯一，各教师独立保存；学生选择本科目当前任课教师配置，新会话绑定教师。
- 保存的解题引导开启时使用固定教学框架，忽略但不删除自定义提示词；关闭后使用自定义或普通默认提示词。
- 本人本班分科会话的新建、列表、读取和删除，最近 6 轮上下文与 SSE 流式回答。
- 短追问可结合最近用户题目重新检索；本班本科目学生资料、原文件指纹、本轮引用编号与真实摘录逐轮核对。
- 引导按进度给提示、概念先解释、接受公式、完成后总结；已有片段支持的公式须要求标注来源，不自动给候选来源挂引用。
- 教师独立助手配置页按班级回读，移除示例密钥和虚构绑定清单；学生快速提问历史由 student-workspace 定义，与服务端会话分开。
- 兼容每日 40 次限制、班级隔离、未改初始密码限制和 Token 刷新。429 超限审计仍待补齐。

## Capabilities

### New Capabilities

- `agent-assistant`: 可配置、带解题引导、多轮会话、SSE 与真实来源核对的学生助手。

### Modified Capabilities

- `rag-search`: 由独立检索变更维护数值降噪、章节辅助排序与来源过滤，本变更复用其结果。
- `student-workspace`: 学科切换、真实技能状态、提问快捷历史和消息展示。

## Impact

后端 AgentConfig、Conversation、Message 及教师配置/学生会话接口；前端 teacher/student 页面、SSE 客户端；Nginx 关闭 API 响应缓冲。旧单次问答端点兼容保留。密钥仅在服务端环境，不提供前端密钥读写。无外部队列或 MCP 实际接入；作业批改与错题技能仍未实现。
