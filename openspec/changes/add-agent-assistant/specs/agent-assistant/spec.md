## Purpose

将 CampusClaw 单次、无状态、提示词硬编码的 AI 解题助手升级为可配置、带「解题引导」技能、支持多轮会话与 SSE 流式输出的对话式智能体，并保持既有的班级知识库检索与溯源、每日限次与班级数据隔离约束。

## ADDED Requirements

### Requirement: 教师的可配置提示词

教师 MUST 能按任教班级和自己的学科自定义 AI 解题助手的系统提示词，并能在任意时刻保存与重新读取。系统 MUST 将配置持久化（class_id、subject、teacher_id 联合唯一，各教师独立），关闭解题引导时，教师留空提示词 MUST 回退到内置默认提示词；开启时 MUST 使用固定引导框架，忽略已保存的自定义提示词但不删除它。教师 MUST 只能配置其任教班级（`teaching_classes` 范围内），越权配置 MUST 返回 403 并记录审计日志。

#### Scenario: 教师保存某班自定义提示词

- **WHEN** 教师在任教班级（如 class_id=101）保存一份自定义系统提示词
- **THEN** 系统将其持久化到本人/该学科/该班级的 AgentConfig，学生在该班关闭解题引导后提问时使用该提示词；开启引导时保留配置但使用固定引导框架

#### Scenario: 留空回退默认提示词

- **WHEN** 教师关闭解题引导并清空某班级的自定义提示词，或该班从未保存过配置
- **THEN** 学生在该班提问时使用内置默认提示词，保留 LaTeX 定界符及直接表达要求，并追加统一引用真实性约束；依据不足时必须如实说明

#### Scenario: 配置非任教班级被拒绝

- **WHEN** 教师尝试保存或读取一个不在其 `teaching_classes` 内的班级配置
- **THEN** 系统返回 403 Forbidden 并记录审计日志

### Requirement: 「解题引导」技能开关

教师 MUST 能按班级开关「解题引导」技能。系统 MUST 将开关状态持久化。开启时 MUST 使用固定苏格拉底引导框架及格式/溯源规则，忽略教师自定义提示词；关闭时 MUST 使用自定义提示词或内置普通默认提示词，不附加引导规则。配置界面的初始开关值为 true；从未保存配置的班级学科实际使用普通默认提示词，教师保存后才应用开关，此边界 MUST 明确区分。系统 MUST 向教师提供技能文案预览。

#### Scenario: 开启解题引导技能

- **WHEN** 教师在班级开启解题引导技能后学生提问
- **THEN** 系统使用固定引导框架替代自定义提示词，AI 只给解题思路引导、不直接给出完全最终答案；自定义提示词仍可回读

#### Scenario: 关闭解题引导技能

- **WHEN** 教师在班级关闭解题引导技能后学生提问
- **THEN** 系统不追加技能文案，AI 按已保存自定义提示词或内置普通默认提示词作答

#### Scenario: 教师预览技能文案

- **WHEN** 教师编辑技能配置或点击技能文案查看
- **THEN** 系统返回"给思路不给答案"的技能文案内容供教师了解并确认

### Requirement: 多轮会话与上下文延续

学生 MUST 能创建多个会话并进入其中一个会话发起连续追问。同一会话内的历史消息（最近的若干轮）MUST 作为上下文在生成回答时传递给大模型，使追问能延续前文。会话 MUST 属于创建它的学生且绑定提问时的班级、学科与所选任课教师，读取/删除/追问会话 MUST 校验归属与班级一致；列表 MUST 按当前学科过滤，检索仅限该班该学科的已索引资料，非本人会话 MUST 返回 404 隐藏存在性，属于本人但班级不一致时 MUST 返回 403。

#### Scenario: 在会话内连续追问

- **WHEN** 学生在同一条个会话内连续发送"什么是向量夹角？""具体怎么算？"等追问
- **THEN** 系统把该会话前几轮的用户与 AI 消息一并作为上下文传给大模型，使"具体怎么算"能接着前文展开

#### Scenario: 新建与列出会话

- **WHEN** 学生点击"新对话"提交问题（或主动创建会话）
- **THEN** 系统创建一个绑定该学生与当前班级的新会话，并在会话列表中可见；问题作为首条消息、以其截断作会话标题

#### Scenario: 访问他人会话被拒绝

- **WHEN** 学生尝试读取或追问一个不属于本人，或属于其他班级的会话
- **THEN** 非本人或不存在时返回 404；本人会话班级不一致时返回 403 并记录审计日志

### Requirement: 删除会话

学生 MUST 能删除本人当前班级下的会话。删除会话 MUST 连同其全部消息一并移除（SQLite 未启用外键级联，需显式清空 `messages` 再删 `conversations`）。删除不存在的会话或他人会话 MUST 返回 404。

#### Scenario: 删除会话并清理消息

- **WHEN** 学生删除某会话
- **THEN** 系统删除该会话及其全部 user/assistant 消息，删除后读取该会话消息返回 404

### Requirement: SSE 流式回答

学生提问后，系统 MUST 以 SSE（`text/event-stream`）返回增量文本和最终结果。生成中增量尚未完成引用核对，前端 MUST 明示此状态；正常 done 事件 MUST 含已校验引用编号的最终答案、实际使用的 citations 和 remaining，并替换临时显示内容。异常 error 事件 MUST 包含最终 message、citations 和 remaining，不承诺额外 done。模型中断后的部分文本 MUST 同样核对编号；完全失败或未配置 Key 时 MUST 展示服务器生成的检索段落及其实际来源。反向代理 MUST 关闭 `/api/` 响应缓冲。

#### Scenario: 流式逐字输出

- **WHEN** 学生在会话内提问且 DeepSeek 正常
- **THEN** 前端显示生成中引用待核对提示，逐字渲染增量，最后用 done 中的最终答案和实际使用的有效来源替换临时内容

#### Scenario: 多轮会话检索无命中时延续历史

- **WHEN** 本班没有相关分块被召回
- **THEN** 多轮会话仍调用模型，传入最近历史及本轮无新资料说明，可延续已有题目；不存在资料时如实说明，引用列表为空。旧单次 ai-question 接口仍直接返回无资料提示

#### Scenario: DeepSeek 失败时降级为检索段落

- **WHEN** 有相关分块但 DeepSeek 调用失败或未配置 API Key
- **THEN** error 事件包含降级 message、段落对应的结构化 citations 和 remaining；前端立即显示与保存到历史一致的最终内容及来源

#### Scenario: 流式结束写回会话

- **WHEN** 流式完成（无论成功或降级）
- **THEN** 系统把 user 消息和完成引用编号核对的 assistant 消息写回会话，sources 仅保存最终答案实际使用的来源，降级段落保存实际展示来源

### Requirement: 消息与会话持久化

系统 MUST 将消息持久化到 `messages`，assistant 消息 MUST 保存经过编号核对的最终内容及实际使用的 sources（JSON 数组），含原 reference_id 和 file_sha256。历史 MUST 按时间正序回显并保留原来源；作为新一轮模型上下文时 MUST 仅取有限轮次，并去除旧 assistant 正文数字来源编号，避免沿用旧编号。旧无版本来源 MUST 明示未记录版本并禁止直接打开原文。

#### Scenario: 回显历史消息

- **WHEN** 学生重新打开某会话
- **THEN** 系统按时间正序返回该会话全部 user/assistant 消息，assistant 消息携带其溯源引用

#### Scenario: 仅带最近若干轮作为上下文

- **WHEN** 会话消息很多、学生继续追问
- **THEN** 系统只取最近 6 轮、最多 12 条消息，去除 assistant 历史中的数字来源编号后再传给模型；原持久化历史不被改写

### Requirement: 兼容既有约束

多轮会话与流式提问 MUST 与既有功能共享约束：AI 提问计数 MUST 复用 `AIQuestionLog` 按北京时间自然日统计（每日 40 次上限，超限返回 429；429 审计尚待补齐）；班级数据隔离 MUST 仍经 `require_student_class_id` / JWT `class_id` 强制，检索仍经 `retrieve_top_k` 限定本班（含 `citations` 溯源）；未分配班级的学生进入问答 MUST 被拒绝（403，前端展示"暂无班级"空状态）。

#### Scenario: 追问计入每日限次

- **WHEN** 学生在会话内每次连续追问
- **THEN** 系统每次计数到当日 40 次限额，达到上限后返回 429，流式结束事件携带剩余次数

#### Scenario: 未分配班级学生被拒

- **WHEN** class_id 为 NULL 的学生尝试创建会话或追问
- **THEN** 系统返回 403，前端展示"暂无班级"空状态，不发请求

#### Scenario: 教师配置与班级检索共享隔离

- **WHEN** 学生提问命中本班分块
- **THEN** 回答仍带 `citations` 溯源且全部来自本班范围，与 `add-rag-search` 行为一致


### Requirement: 按学习进度自适应引导

解题引导开启时 MUST 使用固定系统框架并保留教师自定义提示词但不将其传入模型；本次更新 MUST NOT 改写教师已保存配置。框架 MUST 区分新题、概念疑问、局部纠错、卡住和已完成状态。概念/符号疑问可先简短解释，不强制反问；需要推进时每轮最多一个具体问题。已有作答 MUST 从当前步骤继续，不重复开场。MUST 接受自然语言、数值及学生主动输入的公式，不强制 LaTeX 输入。

学生卡住时 MUST 按知识点、下一步操作、局部示范逐级增加提示，每轮只推进一级，保留目标题关键计算/判断由学生完成；不得因“不会”或索要答案而直接代做完整题目。学生已给出答案时可核对，理由充分后总结结束，不无限追问。缺少题干/图示或可靠依据时先澄清，不猜测；禁止内部检索流程表述，不禁止正常数学连接词。公式格式和统一引用真实性约束继续生效。

以上为模型输入约束，MUST NOT 宣称输出已被程序保证为单问题、数学正确或绝不泄露答案；仍需通过样例评估模型行为。

#### Scenario: 概念与学生公式作答

- **WHEN** 学生询问概念或主动提交公式、计算过程
- **THEN** 先解释具体疑问或检查当前步骤，不要求改成文字，不重新询问已展示的思路

#### Scenario: 多次卡住与完成

- **WHEN** 学生表示不会或已经自行给出最终答案及理由
- **THEN** 前者依据已给提示只提升一级帮助，后者核对并在理由充分时总结结束，不代算整题也不无休止追问

### Requirement: 引导短追问重新检索依据

已保存解题引导开启的多轮会话，对明确的短追问词、数值或简短公式作答，MUST 在最近 12 条历史消息中查找最近独立用户题目，结合原始本轮消息组织检索查询，仍限定当前会话班级和科目，逐轮核对原文件 SHA 和真实分块。不直接复用历史 citations 或编号，不把模型历史回答作为检索题目来源。独立新问题及非引导模式 MUST 使用当前问题检索；没有合适题目或题目超过 2000 字符时保留当前查询，不截断题目条件。本轮用户消息原文与计数/历史保存方式保持。

短追问识别本期使用有限词表及数值/简短公式规则，不宣称理解任意省略表达；历史超出最近 6 轮时可能需要学生重述题目。

#### Scenario: 学生只回复数字或不会

- **WHEN** 同一引导会话已有完整题目，学生回复“2”“x=2”“不会”或“为什么”
- **THEN** 结合最近用户题目重新检索当前班级当前科目资料，原始作答仍作为当前消息传给模型，引用采用本轮核对结果

#### Scenario: 换题或无题目锚点

- **WHEN** 学生提交独立新题，或历史没有适用用户题目
- **THEN** 不拼接不相关旧题，只使用本轮消息检索，资料不足时如实说明，不伪造出处


### Requirement: 使用已有公式依据时标注引用

模型输入 MUST 要求：本轮片段明确提供了正在使用的定义、定理或公式及条件时，在对应说明处标注该片段的 [n]；不得因常见公式而省略已有依据，也不得将具体代入运算冒充原文例题或答案。片段没有直接支持时不补编号。统一约束适用于教师自定义/默认提示词及固定解题引导，响应仍只展示模型实际使用且编号有效的来源，不自动挂上全部候选。

#### Scenario: 引导求两向量夹角余弦

- **WHEN** 本轮有真实夹角公式片段且回答使用该公式引导学生计算数量积
- **THEN** 模型被要求在公式解释处标对应编号，服务端保留有效来源与原文摘录；学生给定坐标的具体计算不伪称来自讲义

#### Scenario: 历史未标注来源的回答

- **WHEN** 旧回答未保存引用，或本轮模型没有标注有效编号
- **THEN** 不对旧记录追补猜测来源，不把所有检索命中当作实际使用；新回答按更新规则处理，不能保证模型每次都遵守
