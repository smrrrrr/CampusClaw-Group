# 安全自查基线

## 为什么做

按用户提供的第8课安全清单和AI代码审核材料，记录现有系统SEC-01至SEC-07的可复现实际结果；先观察，不修复业务实现。

## 范围

- 沿用现有演示账号角色与两班范围，真实库只读确认账号存在、班级和改密状态；实际写入检查使用空临时库、相同演示身份结构、测试口令及假模型/MCP。
- 逐项执行未登录、跨班资料/检索、学生改配置、绕过技能直接写分、密钥历史/前端/日志、依赖审计、技能调用日志追溯。
- 记录并发、事务及权限核查依据，提供可重放自查入口；不把人工交叉评审伪称为完成。
- 报告/检查工具变更，无业务能力变化，因此skip_specs=true，不编造业务规约。

## 不做

不重跑dev_seed、不重置密码、不改教学数据、不更新服务/依赖/提示词、不提前修复红项、不改tasks勾选、不归档/提交/推送。发现真实密钥泄漏另按安全规则处置，报告不输出明文。SEC-08只备材料不运行攻击。
