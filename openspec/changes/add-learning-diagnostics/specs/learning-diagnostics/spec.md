## Purpose

为学生与教师提供基于真实作业、错题与提问记录的学情诊断能力：学生查看本人各学科掌握度、成绩趋势与 AI 学习画像；教师查看班级（全科或单科）学情汇总，含平均分、分数段分布、提交率、错题率与学生掌握度排行。所有数据严格按身份、班级、学科与本人归属隔离。

## ADDED Requirements

### Requirement: 学生本人学情概览

学生 SHALL 能获取本人学情概览统计，MUST 包含累计提问数（本人 user 角色消息数）、作业提交数（本人已提交且教师已批改的提交数）、作业正确率（本人 `teacher_score` 的平均值，四舍五入到整数百分比，无批改记录时为 null）、错题累计数（本人错题记录总数）。统计 MUST 只基于当前会话学生本人数据，MUST NOT 包含其他学生数据。无数据时对应字段 MUST 返回 0 或 null（正确率），不报错。

#### Scenario: 学生查看本人学情概览

- **WHEN** 王芳登录后请求本人学情概览
- **THEN** 返回王芳本人的累计提问、作业提交数、作业正确率、错题累计数，不含李明或其他学生数据

#### Scenario: 无作业批改记录时正确率为 null

- **WHEN** 李明尚无任何教师批改的作业提交
- **THEN** 作业正确率返回 null，其余统计字段返回 0

### Requirement: 学生各学科掌握度

学生 SHALL 能获取本人各学科掌握度数据，MUST 包含每个学科的掌握度分值（0-100）、该学科已批改作业数、错题数、未掌握错题数。掌握度分值 MUST 基于该学科教师批改成绩的平均分与错题未掌握率综合计算（具体算法见 design.md），无该学科数据时掌握度为 null。MUST 同时返回综合掌握度（所有有数据学科的平均值，无数据时为 null）和近期成绩趋势（按作业批改时间倒序的最近 N 条成绩记录，含作业标题、分数、时间、学科）。MUST NOT 返回其他学生的学科数据。

#### Scenario: 学生查看各学科掌握度

- **WHEN** 王芳请求各学科掌握度
- **THEN** 返回本班开设各学科的掌握度分值、作业数、错题数，仅含王芳本人数据

#### Scenario: 无数据学科掌握度为 null

- **WHEN** 李明从未提交过物理作业
- **THEN** 物理学科掌握度返回 null，不伪造分数

#### Scenario: 查看近期成绩趋势

- **WHEN** 王芳请求学情数据
- **THEN** 返回按批改时间倒序的近期成绩列表，每条含作业标题、分数、学科和时间

### Requirement: AI 学习画像

学生 SHALL 能获取 AI 生成的学习画像。系统 MUST 将本人的提问记录统计、各学科掌握度、错题分布作为上下文传入 `llm_service.generate_answer`，要求模型返回学习风格标签、优势学科、待提升学科与学习建议，MUST NOT 直接给出作业答案或暴露其他学生数据。未配置 API Key 时 MUST 返回降级提示而非报错。画像内容 MUST 只基于本人数据。

#### Scenario: 学生获取 AI 学习画像

- **WHEN** 王芳请求学习画像
- **THEN** 返回 AI 生成的学习风格、优势学科、待提升学科与建议，基于王芳本人数据

#### Scenario: AI 未配置时降级

- **WHEN** 王芳请求画像但服务端未配置 API Key
- **THEN** 返回降级提示（如"AI 学习画像暂未配置"），不抛异常

### Requirement: 教师班级学情汇总（班主任全科）

班主任 SHALL 能查看本人 `homeroom_class_id` 班级的全科学情汇总，MUST 包含班级平均分（所有学科教师批改成绩的平均）、各学科平均分、各分数段人数分布（如 <60、60-79、80-100）、作业提交率、错题率、学生掌握度排行（按综合掌握度降序的本班学生列表，含姓名、综合掌握度、主要薄弱学科）。MUST 只包含本人带班班级的数据，跨班请求 MUST 返回 403。MUST NOT 返回学生作答原文或教师评语全文。

#### Scenario: 班主任查看本班全科学情

- **WHEN** 101 班班主任请求本班学情汇总
- **THEN** 返回 101 班全科汇总数据，不含 102 班数据

#### Scenario: 非班主任或跨班请求被拒

- **WHEN** 无带班身份的教师请求班级学情，或 101 班班主任指定 class_id=102
- **THEN** 返回 403

### Requirement: 教师学科学情汇总（任课单科）

任课教师 SHALL 能查看本人 `teaching_classes` 范围内某班级、本 `subject` 学科的学情汇总，MUST 包含本学科班级平均分、分数段分布、提交率、错题率、学生本学科掌握度排行。MUST 校验班级在本人任教范围内且学科为本人任教学科，否则返回 403。MUST NOT 返回其他学科或其他班级数据。

#### Scenario: 任课教师查看本班本学科学情

- **WHEN** 数学教师在任课管理选择 102 班并请求学科学情
- **THEN** 返回 102 班数学学科的汇总数据，不含其他学科或 101 班数据

#### Scenario: 跨学科或跨班请求被拒

- **WHEN** 数学教师请求 102 班英语学情，或请求非任教班级学情
- **THEN** 返回 403

### Requirement: 学情数据隔离与归属

所有学情接口 MUST 按当前会话身份校验范围：学生只能查询本人数据（`student_id` 只从 JWT 取）；班主任只能查询本人带班班级；任课教师只能查询本人任教班级且本人学科的数据。MUST NOT 采信请求中的 `student_id`、`class_id`、`subject` 字段作为授权依据。班级学情汇总 MUST NOT 返回学生作答原文、教师评语全文等隐私内容，只返回聚合统计与排行。

#### Scenario: 请求参数中的 class_id 被忽略

- **WHEN** 101 班班主任在请求中传入 class_id=102
- **THEN** 系统忽略该字段，仍以本人 homeroom_class_id=101 查询，不返回 102 班数据

#### Scenario: 学生不能查看班级学情

- **WHEN** 学生请求教师班级学情汇总接口
- **THEN** 返回 403
