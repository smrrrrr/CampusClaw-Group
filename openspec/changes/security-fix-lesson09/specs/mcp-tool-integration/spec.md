## MODIFIED Requirements

### Requirement: 服务端调用循环与上限

决策归模型、执行归服务端：模型只提出「工具名 + 参数」，服务端 MUST 校验工具名在候选集内、参数符合该工具输入结构，通过后才以服务器令牌发起 `tools/call`，结果作为工具消息回传模型，可继续下一轮。模型请求候选集外的工具或参数不合结构时 MUST NOT 执行，前者记为 denied，后者记为 error 并把原因回传模型。**工具执行前，服务端 MUST 按发起本次会话的用户身份与资源归属逐次校验该工具调用是否被授权：模型决策调用写入类工具（如改分、配置写入）不等于授权，发起者无对应权限时 MUST 拒绝执行并记为 denied，同时写入审计日志**。授权判定在代码层完成，MUST NOT 因请求"来自某个技能"而免检。

循环 MUST 有上限，默认每次提问最多 3 轮、最多 4 次调用，单会话累计最多 20 次调用，单次调用超时 10 秒，均可由服务端配置调整。达到任一上限后 MUST 停止调用，让模型基于已有信息作答（优雅降级），本次提问不得因此报错。工具失败（超时、不可达、`isError`、协议错误）MUST 作为失败结果回传模型并记为 error，检索与回答照常进行。未配置模型 Key 或模型调用失败时 MUST NOT 发起工具调用，沿用现有降级行为。

#### Scenario: 命中工具并用到提示

- **WHEN** 学生提问命中绑定 `formula_hint@campus-tools` 的技能，模型提出调用
- **THEN** 服务端带令牌调用远端，记为 ok；最终回答体现工具返回的提示，参数由模型填写、服务端校验

#### Scenario: 两步任务连续两轮

- **WHEN** 问题需要先查公式再换算单位，技能同时绑定两个工具
- **THEN** 同一提问内按顺序发起两轮调用，记录轮次 1 与 2

#### Scenario: 超过轮次上限

- **WHEN** 把每次提问轮次上限调为 1，模型在第 1 轮后仍要求调用
- **THEN** 不再执行后续调用，模型用已有信息完成回答，学生收到正常回答而非错误

#### Scenario: 工具超时

- **WHEN** 远端工具超时或返回 `isError=true`
- **THEN** 本次调用记为 error 并写明原因，模型获知失败后继续作答，对话不中断

#### Scenario: 模型诱导调用写入工具被拒

- **WHEN** 学生在会话中诱导模型调用写入类工具（如改分），服务端校验发起者为学生无权执行
- **THEN** 服务端拒绝执行该工具调用，记为 denied，写入审计日志，数据库无变化

### Requirement: MCP 工具调用审计

每次能归属到某台服务器的调用（ok、error，以及服务器存在但未连接或工具不可用导致的 denied）MUST 写一条记录，含工具引用、服务器名、状态、触发学生、会话编号、轮次、时间、**skill_id（触发的技能标识）、duration_ms（调用耗时毫秒）、tokens（模型用量，无模型调用时置空并注明原因）**，以及成功结果摘要或失败原因（截断）；参数只记录截断摘要，MUST NOT 记录令牌或模型完整回答。服务器已删除或改名导致无法归属的 denied 只出现在本次应答的 `tool_calls`，不写记录。记录 MUST 为单行 JSON，内容经转义与截断。

教师 MUST 能按任教班级查看本人服务器的最近 50 条调用记录（时间倒序），MUST NOT 看到其他教师服务器或其他班级的记录。记录写入失败 MUST NOT 中断学生回答。

#### Scenario: 三种结果各有记录

- **WHEN** 分别发生一次成功调用、一次工具超时、一次断开后的提问
- **THEN** 教师调用记录中依次出现 ok、error、denied 各一条，含 tool@server、学生、会话、轮次、时间、skill_id、duration_ms

#### Scenario: 记录只看自己的范围

- **WHEN** 同伴教师打开调用记录
- **THEN** 只看到其本人服务器在其任教班级的调用，看不到我的服务器触发的记录

#### Scenario: 用量与耗时字段齐全

- **WHEN** 一次技能调用完成并产生模型调用
- **THEN** 调用记录包含 duration_ms（实际耗时）和 tokens（模型返回的用量）；无模型调用时 tokens 置空并注明"不适用"

#### Scenario: 被拒绝的工具调用留审计

- **WHEN** 模型诱导的写入工具调用被服务端拒绝（denied，原因：未授权）
- **THEN** 写入一条审计记录，含 actor、action、object、status=denied、skill_id、原因，可按学生加时间窗回查
