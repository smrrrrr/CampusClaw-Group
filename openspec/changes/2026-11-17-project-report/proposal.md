# 项目报告与可复核证据整理

## Why

根目录 report.md 目前是冗长的历史交付索引，未按六节报告组织。部分入口仍写旧技术版本、未配置分支保护等历史状态，读者难以区分当前状态和历史证据。

## What Changes

- 将 report.md 整理为六节、适合排成两页的报告，原文保存在 reports/project-history.md。
- 细化 AGENTS.md 已有七类核查责任的可执行问题、手段、判据与证据入口。
- 以实际历史发现和本次复跑补充独立评审记录、并发/事务/权限三查、GitHub 状态快照与贡献索引。
- 增加部署环境四步演示和八分钟汇报指引，明确外部地址由教师后续提供，现场验证尚未完成。
- 更新 README 和 reports/README.md，输出由 report.md 同源生成的 PDF 便于阅读。

## Capabilities

无新增或变更的业务能力。skip_specs: true 仅适用于报告、核查规则说明、证据整理及文档排版工具；不更改产品接口、权限、模型、数据库、门禁判定或既有任务勾选。

## Impact

报告声明必须能链接到文件、实际执行记录或 GitHub PR/CI。外部部署、真实模型表现、真人签名不得由本机替代。当前工作从 PR #6 的文档提交 5cca997 开始，业务基线为 main 8964200，后续提交与合并需按原有保护流程进行。
