# 引用来源与原文版本核对

原提示词允许补全片段中缺失的标准公式后挂上讲义来源，容易把相关内容误当成直接证据。回答还曾返回全部检索候选，来源摘录被截取，历史编号与当前候选之间缺少校验，原文下载没有版本约束。

本次将引用限制为本班当前学科实际检索、文件版本可核对的真实分块。最终回答只携带实际使用的来源，剔除无效编号和自拟数字引用链接；提示词禁止为原文未支持的公式、结论或计算挂来源。旧无版本来源明确标示，不能直接打开。

影响：rag-search、agent-assistant、material-upload、student-workspace。新增 Material.source_sha256，升级保留数据，旧索引需重新索引。保持固定解题引导开启时忽略自定义提示词的既有行为。

边界：编号、摘录、班级学科和文件版本是程序校验；论断是否得到原文直接支持仍受模型能力影响，不承诺自动语义证明或百分之百正确。页码、高亮定位及独立语义核验尚未实现。
