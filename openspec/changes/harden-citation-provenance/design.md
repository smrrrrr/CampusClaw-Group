# 设计

1. 索引前后校验物理文件 SHA-256，稳定时与分块一起记录；失败或文件变化保持未索引。旧库仅追加 nullable 字段。
2. 生成上下文时复查真实 Material、MaterialChunk、本班归属及当前文件哈希，使用完整 chunk.content 作为 excerpt，不生成或改写摘录。资料科目仍按现有发布教师当前科目过滤，没有历史学科快照。
3. 所有系统角色提示词追加统一引用规则，禁止重建缺失公式后冒充讲义来源。传入模型的旧助手消息移除数字来源编号，持久化原历史不改写。
4. 模型输出结束或中断时，按本轮候选映射核对 [n]，移除无效数字引用并提示未核实，数字链接仅保留编号；只保留实际使用的来源，原 reference_id 不重排。不把编号有效当作相邻论断已经通过语义核验。
5. SSE 增量临时展示并提示引用待核对，done/error 返回最终内容、实际来源和剩余次数；来源随最终文本持久化。完全降级时展示服务器构建的真实片段和对应来源。
6. 引用原文请求携带 expected_sha256，下载权限校验后比对当前文件指纹，不一致返回 409。前端正确处理错误响应；旧无指纹引用禁止原文按钮并提示重新提问。普通资料下载仍可不带指纹。

部署前备份现有数据库，部署后通过教师重索引端点更新两份真实讲义。保留账号密码、资料 ID 和原文件；未向真实会话写测试消息。
