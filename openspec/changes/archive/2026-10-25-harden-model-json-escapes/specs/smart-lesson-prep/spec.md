## MODIFIED Requirements

### Requirement: 从定稿生成两种学生稿

系统 MUST 从当前 final 教案和对应原始资料生成 student_lesson（学生可见教案）及 student_handout（配套学生讲义），独立保存并绑定定稿版本。学生可见教案保留目标、知识框架及课堂活动；讲义包含选用题干、知识点及作答空间。两份 MUST 提示去掉题目答案、教师解析与提示，不得带教师私有引用/链接或未选入配图。后端 MUST 拒绝明显答案标记、HTML、外部链接及错误图片路径；普通数学不等式不得误判 HTML。本期为提示词与显式标记检查，MUST NOT 承诺通用答案/图片语义检测，发布前必须人工核对。生成失败保留旧学生稿，修改后核对状态失效。

模型输出 MUST 与智能命题使用同一解析规则：剥除外层代码围栏后，只在 JSON 字符串字面量内部修补 LaTeX 反斜杠（规则同 `smart-question-generation`《结构化输出与逐题校验》），再解析。修补后仍不是合法 JSON 时按生成失败处理。两份学生稿含退格（U+0008）或换页（U+000C）时 MUST 拒绝保存，按未通过检查处理。修补只恢复字符，MUST NOT 宣称证明公式正确。

#### Scenario: 教师生成并修改学生讲义

- **WHEN** 当前教案已定稿，生成两份学生稿并修改其中一份
- **THEN** 可独立预览两稿并保存；重新核对前不能发布，教师完整稿及来源不受影响

#### Scenario: 学生稿生成未通过检查

- **WHEN** 模型返回修补后仍无效的 JSON、明显解答标记或未授权图片
- **THEN** 提示重试，旧稿保持，不能保存或发布失败结果

#### Scenario: 学生稿中的单反斜杠公式被修补

- **WHEN** 模型返回的 `student_handout` 含单反斜杠 `\vec{a}`、`\frac{1}{2}` 与合法换行 `\n`，其余格式合法
- **THEN** 两份学生稿正常保存，公式还原为 LaTeX 命令，换行保留，正文不含控制字符

#### Scenario: 学生稿含漏网控制字符

- **WHEN** 解析后的 `student_lesson` 含换页符（U+000C）
- **THEN** 提示重试，旧学生稿保持不变
