## Why

第 6 课要求把「工具调用」真正接进学生助手：自建一个 MCP 工具服务，由 CampusClaw 登记、连接、发现其工具，并在学生提问命中技能时由服务端鉴权调用、记录审计。当前助手配置页的「上传 / 注册技能」和「MCP 服务器」只是界面预览（agent-assistant 规约「高级助手控件的预览边界」），项目也没有课程第 5 课的技能文件实体，无法承载 `工具名@服务器名` 绑定。

## What Changes

- 新增同仓 `mcp-server/` 工具服务，由 `docker-compose.yml` 一并构建，仅在 Compose 内网暴露。实现 `POST /mcp`（JSON-RPC 2.0：`initialize`、`tools/list`、`tools/call`）与 `GET /health`；Bearer 令牌取自环境变量 `MCP_AUTH_TOKEN`，缺失或错误返回 401。首批两个只给提示、不给最终答案的工具：`formula_hint`（数学公式/步骤提示）与 `unit_convert`（物理单位换算提示），分别对应现有数学、物理任课教师。
- 新增 MCP 服务器管理（教师）：按任教班级登记服务器名称、Base URL 与令牌，令牌只存服务端且用服务端环境变量 `MCP_TOKEN_KEY` 加密落库，响应只回 `has_auth`；「连接」= 握手 + 发现并整体替换工具缓存，「断开」= 清空缓存且不可再调用；失败停在未连接并给出可读原因，不影响现有检索与流式对话。Base URL 须命中服务端允许的主机清单，防止借服务端访问任意内网地址。
- 新增教师技能文件（替代「上传 / 注册技能」预览）：按班级、学科、教师保存 `名称 / 适用条件 / 工具 / 启用 + 说明` 格式的技能。「工具」支持内置 `knowledge_search` 与 `工具名@服务器名`；保存时校验格式、服务器归属、已连接及工具在发现清单内，否则拒绝保存。
- 学生提问命中技能且技能带 MCP 工具时，服务端把候选工具转为工具声明交给模型，按输入结构校验模型提出的参数后带令牌调用 `tools/call`，结果经安全检查后作为数据（不进系统提示）回传，可多轮；设轮次、单次提问调用数、单会话累计调用数上限，超限后停止调用并用已有信息作答。
- SSE 新增先于正文的 `meta` 事件，含命中技能与 `tool_calls`（引用、状态 ok/denied/error、提示摘要）；未连接、不在清单或越权的调用记为 denied，不静默成功。学生端在回答开始前展示本次使用的工具。
- 新增 MCP 工具调用审计：每次可归属到服务器的调用留一条记录（tool@server、状态、触发学生、会话与轮次、时间、摘要或原因），教师只看到本人服务器在本班的记录。
- 补充 MCP、技能接口的 OpenAPI 注解；Swagger 经 Nginx 在本地小组环境可打开（由 `.env` 的 `ENABLE_DOCS` 控制，默认仍关闭）。
- 在 `apitest/` 增加 MCP 管理、技能保存及「连接 → 绑定 → 提问 → 审计 ok」链路用例。

## Capabilities

### New Capabilities

- `mcp-tool-integration`: 自建 MCP 工具服务、教师登记/连接/发现/断开服务器、令牌边界、工具引用解析与保存期校验、服务端调用循环与上限、工具返回的信任边界、调用审计及接口文档。

### Modified Capabilities

- `agent-assistant`: 新增教师技能文件及学生提问的技能路由；移除「高级助手控件的预览边界」，由新增的「助手技能与 MCP 配置界面」替代（技能注册与 MCP 为真实功能，作业批改与错题讲解仍为预览）；「SSE 流式回答」增加先于正文的 `meta` 事件与 `tool_calls`。

## Impact

- 新目录 `mcp-server/`（独立镜像）；`docker-compose.yml` 新增 `mcp-tools` 服务及 `MCP_AUTH_TOKEN`、`MCP_TOKEN_KEY`、`MCP_ALLOWED_HOSTS`、`ENABLE_DOCS` 变量；`deploy/nginx.conf` 增加 `/docs`、`/openapi.json` 转发；根目录 `.env.example` 增加对应空值说明。
- 后端：新增服务器、工具缓存、技能、调用记录四张表（启动 `create_all` 建表，不改旧表结构）；新增 `/api/mcp/*`、`/api/teacher/skills*` 路由；`llm_service` 增加带工具声明的非流式决策调用；学生 `chat` 在命中带 MCP 工具的技能时增加调用循环与 `meta` 事件。
- 前端：教师助手配置页的技能与 MCP 区域接真实接口，作业批改/错题讲解开关仍为预览；学生助手页处理 `meta` 事件并展示工具栏。
- 数据交接：新表含加密令牌和学生调用记录。加密密钥不随数据库分发，换机恢复后已登记服务器须重新填写令牌；今后的数据交接包仍须清空令牌列与调用记录（与现有个人日志清理口径一致）。
- 不改变：未命中带 MCP 工具技能的提问仍走现有单次流式路径；检索、引用核对、每日 40 次额度、班级/学科隔离保持现状；未配置 DeepSeek Key 时不发起任何工具调用并沿用现有降级。
