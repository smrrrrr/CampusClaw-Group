## ADDED Requirements

### Requirement: 教师技能文件

任课教师 MUST 能在任教班级、本人学科下新建、查看、改写和删除助手技能。技能 MUST 归属班级、学科与教师，同一范围内名称唯一；其他教师或其他班级的技能按编号访问 MUST 返回与不存在一致的 404，非教师访问返回 403，非任教班级返回 403。

技能以技能文件原文提交：空行以上逐行为 `名称：`、`适用条件：`、`工具：`、`启用：`（可选 `资料：`，若填写必须等于教师当前学科名称），空行以下为技能说明。名称最长 32 字，适用条件为逗号或顿号分隔的关键词、最长 120 字，说明最长 2000 字，整份文件最长 8000 字；启用只能为「是」或「否」；工具为逗号分隔的 `knowledge_search` 与 `工具名@服务器名` 引用，MCP 引用 MUST 通过 mcp-tool-integration 规约的保存期校验。缺少空行、缺少必填行、未知字段、超长或重名 MUST 返回 400 及可读原因，MUST NOT 部分保存。

`knowledge_search` 表示沿用现有本班本科目资料检索；本期检索仍对每次提问执行，MUST NOT 因技能未列出 `knowledge_search` 而关闭检索或改变引用核对。技能说明属于教师配置，MUST NOT 覆盖解题引导开启时「不代做完整目标题」的固定约束。

#### Scenario: 保存绑定 MCP 工具的技能

- **WHEN** 数学教师在 101 班提交名称「公式提示」、适用条件「夹角,公式」、工具 `knowledge_search, formula_hint@campus-tools`、启用「是」及说明，且 `campus-tools` 已连接并发现该工具
- **THEN** 返回 201 及解析后的名称、适用条件、工具列表、启用状态与原文；该技能只在 101 班数学、该教师范围内可见

#### Scenario: 技能文件格式错误

- **WHEN** 技能文件缺少分隔说明的空行、启用写成「开启」，或与本范围已有技能重名
- **THEN** 返回 400 并说明具体问题，不新增或改写任何技能

#### Scenario: 他人技能不可见

- **WHEN** 另一位教师按编号读取、改写或删除我的技能
- **THEN** 返回 404，与访问不存在编号一致

### Requirement: 学生提问的技能路由

学生在会话中提问时，服务端 MUST 只在该会话绑定教师于本班本科目保存且已启用的技能中路由：本轮检索查询（含已有短追问补全规则）包含任一适用条件关键词（不区分大小写）即命中，多条命中时取编号最小的一条。命中技能的说明 MUST 作为本轮系统提示中带固定边界声明的独立段落；技能绑定 MCP 工具时按 mcp-tool-integration 规约进入调用循环。未命中任何技能，或命中技能不含 MCP 工具时，提问 MUST 保持现有单次流式生成路径，不额外调用模型。

#### Scenario: 命中技能

- **WHEN** 学生在数学会话问「两向量夹角怎么求」，绑定教师有适用条件含「夹角」的启用技能
- **THEN** 本轮使用该技能说明并可调用其绑定工具，`meta` 事件显示技能名称

#### Scenario: 未命中或技能停用

- **WHEN** 问题不含任何启用技能的关键词，或匹配的技能启用为「否」
- **THEN** 按现有提示词、检索与流式路径回答，不出现 `meta` 事件，不调用工具

### Requirement: 助手技能与 MCP 配置界面

助手配置页 MUST 以提示词、AI 技能/助手参考资料和 MCP 区域组织内容。技能注册与 MCP 服务器管理 MUST 接入真实接口：技能区列出本班本科目本人技能并支持以技能文件新建、改写、删除；MCP 区支持登记、修改、删除、连接并发现、断开服务器，展示已发现工具的完整说明与参数，以及最近调用记录。令牌输入框 MUST 为密码类型，提交后清空、不回显，列表只显示是否已配令牌。本期作业批改与错题讲解开关仍 MUST 仅作为界面预览，MUST NOT 将其本地状态当作服务端配置。

教师端 MUST NOT 提供示例 API Key、模型密钥显示按钮或真实模型密钥读取/编辑入口。模型运行密钥继续由服务端环境配置提供，MUST NOT 返回前端或进入代码仓库；本期不新增模型密钥配置状态接口，不用静态文字宣称服务已配置。真实配置为提示词、`tutor_enabled`、技能与 MCP 服务器；学生页的解题引导徽标 MUST 从本班该科教师配置接口读取，MUST NOT 将作业批改/错题讲解的预览当作真实技能。

#### Scenario: 在配置页登记并连接 MCP 服务器

- **WHEN** 教师在助手配置页填写服务器名称、Base URL 与令牌后保存，再点击连接
- **THEN** 列表显示已配令牌与已连接状态及发现的工具，令牌输入框已清空，页面任何位置不显示令牌

#### Scenario: 以技能文件注册技能

- **WHEN** 教师在技能区粘贴技能文件并保存
- **THEN** 调用技能接口保存，成功后列表出现该技能；校验失败时显示服务端返回的具体原因

#### Scenario: 打开教师助手配置

- **WHEN** 教师打开助手配置页
- **THEN** 不出现示例模型密钥或显示密钥按钮，现有提示词与解题引导保存流程保留

#### Scenario: 调整预览技能不产生真实批改配置

- **WHEN** 教师切换作业批改或错题讲解开关
- **THEN** 只改变当前页面预览状态，不承诺跨页面持久化或学生端生效

## MODIFIED Requirements

### Requirement: SSE 流式回答

学生提问后，系统 MUST 以 SSE（`text/event-stream`）返回增量文本和最终结果。命中技能时，系统 MUST 在第一个增量之前发送 `meta` 事件，含 `skill.name`；本轮存在工具调用或被拒引用时 `meta` MUST 含按发生顺序排列的 `tool_calls`（`ref`、`status` 为 ok/denied/error、成功提示摘要或失败原因），每完成一轮调用推送一次累计列表；无调用时 MUST 省略 `tool_calls` 而不是给空数组，未命中技能时不发送 `meta`。`tool_calls` MUST NOT 含令牌或服务器地址。前端 MUST 在回答正文开始前展示本次使用的工具及状态，并忽略不认识的事件类型；本期历史回显不恢复工具栏。

生成中增量尚未完成引用核对，前端 MUST 明示此状态；正常 done 事件 MUST 含已校验引用编号的最终答案、实际使用的 citations 和 remaining，并替换临时显示内容。异常 error 事件 MUST 包含最终 message、citations 和 remaining，不承诺额外 done。模型中断后的部分文本 MUST 同样核对编号；完全失败或未配置 Key 时 MUST 展示服务器生成的检索段落及其实际来源。反向代理 MUST 关闭 `/api/` 响应缓冲。

#### Scenario: 流式逐字输出

- **WHEN** 学生在会话内提问且 DeepSeek 正常
- **THEN** 前端显示生成中引用待核对提示，逐字渲染增量，最后用 done 中的最终答案和实际使用的有效来源替换临时内容

#### Scenario: 工具事件先于正文

- **WHEN** 学生提问命中绑定 `formula_hint@campus-tools` 的技能并发生一次成功调用
- **THEN** 事件顺序为 `meta`（含该引用、status=ok 与提示摘要）→ `delta` → `done`，页面在第一个字出现前已显示所用工具

#### Scenario: 断开后的引用显示被拒

- **WHEN** 技能引用的服务器已断开或已删除，学生提问命中该技能
- **THEN** `meta.tool_calls` 中该引用为 denied，回答仍正常生成，不静默显示成功

#### Scenario: 多轮会话检索无命中时延续历史

- **WHEN** 本班没有相关分块被召回
- **THEN** 多轮会话仍调用模型，传入最近历史及本轮无新资料说明，可延续已有题目；不存在资料时如实说明，引用列表为空。旧单次 ai-question 接口仍直接返回无资料提示

#### Scenario: DeepSeek 失败时降级为检索段落

- **WHEN** 有相关分块但 DeepSeek 调用失败或未配置 API Key
- **THEN** error 事件包含降级 message、段落对应的结构化 citations 和 remaining；前端立即显示与保存到历史一致的最终内容及来源；不发起工具调用

#### Scenario: 流式结束写回会话

- **WHEN** 流式完成（无论成功或降级）
- **THEN** 系统把 user 消息和完成引用编号核对的 assistant 消息写回会话，sources 仅保存最终答案实际使用的来源，降级段落保存实际展示来源

## REMOVED Requirements

### Requirement: 高级助手控件的预览边界

**Reason**: 技能注册与 MCP 服务器管理改为真实功能，原「技能上传/注册、MCP 添加/连接仅为预览，点击提示尚未接入」的约束不再成立。

**Migration**: 由本变更新增的「助手技能与 MCP 配置界面」替代：技能与 MCP 接真实接口；作业批改、错题讲解开关仍为预览；模型密钥不进入前端的约束原样保留。
