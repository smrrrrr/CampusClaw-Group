## ADDED Requirements

### Requirement: 公式结构校验

公式结构检查是《结构化输出与逐题校验》中逐题校验的一部分。生成、修改保存和通过三处 MUST 执行同一检查。

检查范围：题干、每个选项文本、答案中的字符串（填空题的每一项、解答题的答案）、解析。判断题的布尔答案和选择题的选项字母不在范围内。规则如下：

- 转义的 `\$` 不计为公式定界符。其余 `$` MUST 按 `$$…$$`、`$…$` 成对，否则该字段判为「公式定界符 $ 不成对」。
- 每段公式内，反斜杠与其后一个字符视为一个整体，不参与计数（如 `\{`、`\}`、`\\`）。其余 `{` 与 `}` MUST 配对：从左到右任何时刻右括号都不多于左括号，且结束时数量相等，否则该字段判为「公式花括号不配对」。
- 公式外的花括号不检查。

任一字段不满足时：

- 该题判为未通过，原因 MUST 带字段名，如「选项 D 公式花括号不配对」「题干公式定界符 $ 不成对」；
- 生成时该题 MUST NOT 落库，修改保存与通过 MUST 返回 400。
- 服务端 MUST NOT 自动补全或删除括号与定界符。

本检查只针对 `$` 与花括号，MUST NOT 宣称证明公式可被正确渲染。已通过入库的题目不重新校验。

提示词 MUST 要求公式中的花括号成对，并要求把资料中 `\vec a`、`\frac12` 这类省略括号的写法改写为完整写法（`\vec{a}`、`\frac{1}{2}`）。

#### Scenario: 选项缺右括号

- **WHEN** 模型返回的单选题选项 D 为 `$\frac{1}{2}\vec{a}+\frac{1}{2}\vec{b}+\frac{2}{3}\vec{c$`，其余字段合法
- **THEN** 该题未通过校验，原因含「选项 D 公式花括号不配对」，不以待复核状态保存，其余合格题目照常保存

#### Scenario: 转义括号与环境不被误判

- **WHEN** 某题题干含 `$\{x\mid x>0\}$`，解析含 `$$\begin{cases}x+y=1\\x-y=0\end{cases}$$`
- **THEN** 公式结构检查通过

#### Scenario: 定界符不成对

- **WHEN** 某题解析为 `所以 $\frac{1}{2}`（缺少闭合的 `$`）
- **THEN** 该题未通过校验，原因含「解析公式定界符 $ 不成对」

#### Scenario: 转义的美元符号

- **WHEN** 某题题干为 `单价 \$5，求 $x$ 的值`
- **THEN** 公式结构检查通过

#### Scenario: 修改时引入不配对括号

- **WHEN** 作者修改一道待复核单选题，把选项 A 改为 `$\vec{a$` 后保存
- **THEN** 返回 400，原因含「选项 A 公式花括号不配对」，题目内容与 `revision` 不变

#### Scenario: 修改补齐括号后通过

- **WHEN** 作者把一道选项缺右括号的待复核题（变更前已入库）补齐括号后保存，再勾选确认并通过
- **THEN** 保存成功，通过后进入题库，复核记录标明「已修改」

### Requirement: 学生卷选项排版

服务端渲染学生卷时，每道题以 `n. 题干` 开头，记题号前缀 `n. ` 的长度为该题的缩进宽度。题干与选项的续行 MUST 按该宽度缩进，使其留在同一列表项内；题号到两位数时同样适用。

选择题（单选、多选）的选项 MUST 与题干分段，并按 A–D 顺序各占一行显示：

- 选项文本都不含换行时，选项之间用 Markdown 硬换行连接；
- 任一选项文本含换行时，每个选项单独成段。

判断题、填空题的输出不变；解答题的作答横线不变。本需求只改学生卷正文的排版，不改题目快照，也不改答案卷。已发布的班级资料 MUST NOT 被改写。排版改变后，含选择题的试卷重新发布时按新的学生卷指纹处理。

#### Scenario: 选项各占一行

- **WHEN** 教师预览一份含 2 道单选题的已定稿试卷
- **THEN** 每道单选题的题干单独一段，A、B、C、D 四个选项各占一行、与题干不在同一行，选项中的公式正常渲染，页面 `.katex-error` 为 0

#### Scenario: 第 10 题以后

- **WHEN** 试卷有 12 道单选题
- **THEN** 第 10–12 题的选项仍显示在各自题目下，题号 1–12 连续，选项不会脱离所在题目

#### Scenario: 选项含块级公式

- **WHEN** 某单选题的选项 B 含两行的 `$$…$$` 公式
- **THEN** 四个选项各自成段，块级公式正常渲染，后续题号连续

#### Scenario: 学生端打开新发布的试卷

- **WHEN** 教师在变更后发布一份含选择题的试卷，学生在本班资料中打开
- **THEN** 选择题选项各占一行，且学生卷不含答案、解析与出处

#### Scenario: 已发布资料不被改写

- **WHEN** 变更前已发布的试卷资料被学生再次打开
- **THEN** 资料内容与发布时一致
