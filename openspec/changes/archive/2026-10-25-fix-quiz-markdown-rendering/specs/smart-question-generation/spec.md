## ADDED Requirements

### Requirement: 题目内容显示

前端 MUST 用共用的 Markdown + KaTeX 渲染器（`MarkdownAnswer`）显示题目内容，包括：题库与待复核列表中的题干；题目详情中的题干、选项、答案与解析；草稿与已定稿试卷中的题干；学生卷预览；学生端打开的已发布试卷资料。编辑模式的输入框 MUST 显示原文，不做渲染。

选择题的每个选项 MUST 与题干一样经过渲染，公式 MUST NOT 以 `$…$` 源码显示；选项标签与内容 MUST 显示在同一行（选项含块级公式时除外）。

题目详情的答案：填空题与解答题的答案 MUST 经过同一渲染器，公式 MUST NOT 以 `$…$` 源码显示；填空题多个空位的答案按顺序用「、」分隔。单选、多选题的选项字母与判断题的「正确 / 错误」MUST 保持纯文本显示。答案卷下载的 Markdown 不在本需求范围内。

填空空位：渲染前，正文中连续 4 个及以上的下划线（与后端空位判定一致）MUST 转为按字面显示、不参与 Markdown 强调解析的形式，长度与数量不变。以下内容 MUST NOT 改动：代码块与行内代码、`$…$` / `$$…$$` 公式内部、尖括号自动链接、前面已有反斜杠的下划线、整行只有下划线的行（学生卷解答题作答横线与分隔线保持横线显示）。该规则作用于共用渲染器，因此在 AI 回答、讲义与学生稿预览中同样生效。

本需求只约束显示：MUST NOT 修改已保存的题目、试卷快照或学生卷 Markdown，不改变接口与服务端校验。

#### Scenario: 多空位填空题显示

- **WHEN** 教师在待复核列表或详情中查看题干为 `…则 $\overrightarrow{EF}$ 的坐标为____，____，____。` 的填空题
- **THEN** 页面显示 3 个空位，无加粗或斜体，公式正常渲染

#### Scenario: 空位与公式下标共存

- **WHEN** 题干同时含 `$ABCD-A_1B_1C_1D_1$` 与空位 `____`
- **THEN** 公式下标正常渲染，空位按字面显示，`.katex-error` 数为 0

#### Scenario: 选项含公式

- **WHEN** 教师打开选项为 `$(1,2,2)$`、`$(1,-2,2)$` 等的单选题详情（待复核或题库）
- **THEN** 四个选项都以数学符号渲染，每项「A. 内容」在同一行，页面 `.katex-error` 数为 0

#### Scenario: 填空与解答题答案含公式

- **WHEN** 教师打开答案为 `["$\frac{\sqrt{15}}{5}$"]` 的填空题详情，或答案为 `$\frac{\sqrt{3}}{3}$` 的解答题详情
- **THEN** 答案以数学符号渲染，不显示 `$` 源码，页面 `.katex-error` 数为 0

#### Scenario: 多空答案与选择判断答案

- **WHEN** 教师打开答案为 `["1","1","-1"]` 的填空题，以及单选、多选、判断题的详情
- **THEN** 填空答案显示为 `1、1、-1`；选择题显示选项字母（多选用「、」分隔），判断题显示「正确」或「错误」，与修改前一致

#### Scenario: 编辑答案时显示原文

- **WHEN** 教师在待复核详情中点击修改
- **THEN** 答案输入框显示原文（含 `$…$`），不做渲染

#### Scenario: 解答题作答横线不变

- **WHEN** 教师预览含解答题的学生卷
- **THEN** 作答区仍显示为横线，不变成一串下划线文字

#### Scenario: 学生端打开已发布试卷

- **WHEN** 学生在本班资料中预览含多空位填空题的已发布试卷
- **THEN** 每道填空题的空位数与题干原文一致

#### Scenario: 代码中的下划线

- **WHEN** 渲染内容在行内代码或代码块中含 `____`
- **THEN** 代码原样显示，不出现多余的反斜杠
