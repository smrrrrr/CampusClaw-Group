# student-workspace Specification

## Purpose

按参考界面组织学生导航与学习页面：本班首页、讲义与检索、助手对话、交作业、错题、学情分析。本期实现界面与已有资料/会话接口的衔接；作业、错题和学情业务后续接入。

## Implementation Status

截至 2026-10-20（模块边界按当前实现更新）：

| 模块 | 当前实现 | 尚未实现或尚未验证 |
| --- | --- | --- |
| 首页 | 当前姓名/班级、4 张统计卡、5 个快捷入口 | 统计为固定演示值，未接实时聚合 |
| 讲义与检索 | 本班资料列表、搜索历史、基于元数据的学科过滤、预览/下载 | 页面未实现分块检索结果及命中位置展示；元数据过滤不是严格学科权限隔离 |
| 助手对话 | 本人会话、新建/选择/删除、连续追问、SSE、Markdown/公式、来源查看、分科提问快捷历史 | 已接入按学科的教师配置、历史和资料隔离；作业批改、错题讲解技能仍待实现 |
| 交作业 | 两张数学演示作业卡、答案、分数、评语与错题跳转 | 无真实提交、异步批改队列、教师终评或持久化 |
| 错题 | 一张演示错题、作答和错因、跳转助手 | 无真实错题自动收录、保存或定向讲解接口，跳转未自动携带题目 |
| 学情分析 | 统计、雷达、环图、趋势、热力条和学习画像展示 | 全部为演示数据，无真实统计、AI 画像生成或持久化 |
| 验证 | TypeScript 检查、Next.js 生产构建、CSS 资源请求通过 | 近期使用实际页面与模拟接口验证快捷历史交互；未重做真实学生身份全部页面端到端验收 |

## Requirements

### Requirement: 学生导航与路由

学生端 MUST 统一显示“本班首页、讲义与检索、助手对话、交作业、错题、学情分析”六个菜单项，MUST NOT 显示“关怀式对话”。首页 MUST 有通向除首页外五个模块的快捷入口。资料页 MUST 复用相同学生导航。当前菜单 MUST 高亮，刷新或直接进入有效页面链接时 MUST 能解析对应视图。

| 菜单 | 路由 |
| --- | --- |
| 本班首页 | `/student` |
| 讲义与检索 | `/materials` |
| 助手对话 | `/student?view=assistant` |
| 交作业 | `/student?view=assignments` |
| 错题 | `/student?view=mistakes` |
| 学情分析 | `/student?view=analytics` |

#### Scenario: 首页进入助手对话

- **WHEN** 学生点击“向助手提问”快捷卡或助手对话菜单
- **THEN** 进入 `/student?view=assistant` 并高亮助手对话，侧栏保留全部六个菜单

#### Scenario: 资料页返回其他模块

- **WHEN** 学生从讲义与检索点击交作业
- **THEN** 进入 `/student?view=assignments`，保持学生端导航结构

#### Scenario: 无效视图回退

- **WHEN** 学生访问 `/student?view=unknown`
- **THEN** 显示本班首页，不新增未知菜单或关怀式对话页面

### Requirement: 学生身份与班级上下文

学生工作空间 MUST 使用当前登录学生的姓名、班级和身份，提供退出入口，MUST NOT 提供选择孩子或其他学生的数据入口。学生无班级时 MUST 显示“暂无班级”提示并停止依赖班级的资料/会话请求。班级 101、102 的开发展示名称 MUST 分别为“高二（1）班”“高二（2）班”。教师访问 `/student` MUST 按角色路由规则被拒绝，而不是作为学生页面预览方式。

#### Scenario: 学生首页展示本人班级

- **WHEN** 李明登录进入学生端
- **THEN** 展示李明与高二（1）班的学习空间，不展示王芳的个人数据或其他班级选择器

#### Scenario: 未分班学生访问

- **WHEN** 当前学生 `class_id=null`
- **THEN** 显示联系教师或管理员的空状态，不请求班级资料或会话接口

### Requirement: 本班首页概览

学生首页 MUST 显示本人问候、本班学习空间说明，以及本班讲义、进行中作业、待提交、我的错题四张概览卡。快捷区 MUST 包含向助手提问、检索讲义、提交作业、错题讲解、学情分析。当前统计值属于固定演示数据，MUST NOT 被当作后端聚合或真实学习记录的验收结果。

#### Scenario: 浏览首页概览

- **WHEN** 已分班学生打开首页
- **THEN** 能看到四张统计卡和五张快捷卡，快捷卡可进入对应模块

### Requirement: 本班讲义列表与检索界面

讲义与检索页 MUST 读取当前学生本班的资料接口，提供搜索输入、回车/搜索按钮、真实搜索历史，以及“全部、数学、语文、英语、物理、化学”过滤项。MUST NOT 再用固定数学关键词冒充快捷历史。当前学科过滤 MUST 仅对已返回资料的文件名、描述和标签进行匹配，MUST NOT 被描述为后端按学科授权或完整知识库语义检索。

资料 MUST 以卡片展示文件名、描述、标签、大小、时间和可用的预览/下载操作；空结果或失败 MUST 保留空状态/错误反馈。

#### Scenario: 学生搜索本班讲义

- **WHEN** 学生输入“求根公式”或点击本人搜索历史中的同名关键词
- **THEN** 调用本班资料列表搜索并展示结果，后端仍验证当前学生班级

#### Scenario: 学科标签过滤资料卡

- **WHEN** 学生选择“数学”
- **THEN** 仅展示当前结果中文件名、描述或标签含“数学”的资料；不请求未实现的分学科知识库接口

#### Scenario: 预览和下载实际资料

- **WHEN** 学生对有权限的资料点击预览或下载
- **THEN** 通过现有资料接口查看原文件；学生没有上传或删除入口

### Requirement: 助手对话保留真实会话能力

助手对话页 MUST 保留本人当前班级的会话列表、新对话、历史选择、删除、连续提问、流式回答和引用来源；回答 MUST 保留 Markdown 与 LaTeX 渲染。界面 MUST 展示学习助手标题、学科标签、技能状态区域和解题引导说明。

数学/语文/英语/物理/化学标签 MUST 实际切换科目，按本人班级读取该科任课教师配置与历史。解题引导状态 MUST 来自后端，作业批改及错题讲解 MUST 标为尚未接入。实际会话、提示词和技能行为 MUST 以 `agent-assistant` 后端契约为准，不能以静态状态文案作判断。

#### Scenario: 从助手页连续追问

- **WHEN** 学生在同一会话提交问题并继续追问
- **THEN** 使用现有会话与 SSE 接口，保留历史与来源，遵循每日限额及本人/本班隔离

#### Scenario: 查看回答来源

- **WHEN** 助手消息包含来源引用
- **THEN** 按 reference_id 显示文件名、块序号及真实分块摘录；有 file_sha256 时校验版本后打开原文，版本变化显示错误；旧无版本来源提示重新提问并禁用原文按钮，没有来源时不伪造引用

### Requirement: 作业界面先展示演示结果

交作业页 MUST 展示作业标题、题目、截止时间、状态、本人作答、分数与评语卡片；当前可使用“一元二次方程练习”和“函数单调性判断”两项固定演示数据。演示界面 MUST NOT 被视为真实提交、批改任务、教师评分或持久化已经完成。

#### Scenario: 浏览演示作业结果

- **WHEN** 学生打开交作业页
- **THEN** 展示两张演示卡片与 95/60 分示例，错题卡可跳转错题页，不产生真实提交或批改任务

### Requirement: 错题界面及助手跳转

错题页 MUST 展示题目、本人作答和错因，并提供“请助手讲解”入口。本期内容 MUST 可为固定演示；点击讲解 MUST 进入现有助手对话页面，不代表已实现自动携带错题、智能归因或错题收录接口。

#### Scenario: 由错题进入助手

- **WHEN** 学生点击演示错题中的“请助手讲解”
- **THEN** 导航到 `/student?view=assistant`，不自动创建或提交一条讲解请求

### Requirement: 学情分析演示界面

学情分析页 MUST 展示累计提问、作业提交、作业正确率、错题累计，以及各学科掌握度雷达图、综合掌握环图、近期趋势、掌握热力和 AI 学习画像区域。本期 MUST 可采用本地静态演示数据；这些图表与建议 MUST NOT 被记录为真实学习诊断服务已完成。

#### Scenario: 浏览学习画像演示

- **WHEN** 学生打开学情分析
- **THEN** 页面展示带本人姓名的图表和建议，并使用演示数据说明；不调用或创建未实现的画像生成任务



### Requirement: 讲义页科目切换布局稳定

学生讲义页 MUST 使用始终存在的页面标识决定容器宽度，MUST NOT 根据是否出现资料卡片网格切换父容器宽度。宽屏上限统一为 1420px；学科按钮、搜索栏和结果标题在有资料、空结果和加载状态 MUST 保持同一布局。结果标题持续显示当前科目，结果区保留至少 300px 高度，空科目显示“暂无某科资料”，通过预留滚动条空间避免内容高度变化导致横向位移。该布局修复 MUST NOT 修改教师列表宽度、资料、账号或既有筛选权限逻辑。

#### Scenario: 从有资料切到空科目

- **WHEN** 学生由数学或全部切换到暂无资料的科目
- **THEN** 只更新当前科目标题及结果内容，页面和搜索栏不收窄、不横向跳动，空态说明保留

#### Scenario: 搜索加载与恢复

- **WHEN** 搜索正在加载或完成后重新出现资料
- **THEN** 使用相同外层容器、结果标题与列表区域，页面宽度不依赖是否渲染卡片

### Requirement: 学生本地搜索与提问历史

学生讲义页 MUST 在搜索框下展示真实“搜索历史”，学生助手 MUST 在输入区附近展示“提问历史”。两种历史 MUST 分别按学生 ID、班级和当前科目隔离，使用当前浏览器 localStorage 保存，不承诺跨设备同步。“全部”资料筛选具有独立历史。MUST 仅记录主动执行的非空搜索或实际提交的非空问题，不记录输入草稿、自动列表加载或仅点击回填的问题。记录去除首尾空白、去重、最近使用排前，每个范围最多 10 条；超过 4000 字符的内容不存入快捷历史，但不改变原请求。

点击讲义历史 MUST 回填并按原接口重新搜索；点击提问历史 MUST 仅回填并聚焦输入框，MUST NOT 自动创建会话、发送问题或触发 AI。生成或加载助手期间 MUST 禁用历史回填。清空 MUST 只删除当前范围的快捷历史，不删除真实会话、消息、其他科目或账号的记录。无历史 MUST 提供空态说明；长记录按钮省略显示、完整文本回填。浏览器拒绝存储或内容损坏 MUST NOT 阻塞搜索、对话，拒绝存储时可仅在当前页面内存保留。

#### Scenario: 搜索后刷新与再次使用

- **WHEN** 学生搜索同一关键词两次、刷新页面并点击该历史
- **THEN** 历史只保留一条，刷新后可见，点击后调用本班原搜索接口

#### Scenario: 科目和账号隔离

- **WHEN** 学生切换科目或另一学生登录
- **THEN** 不显示原范围历史，返回原范围恢复其记录，不短暂展示其他范围内容

#### Scenario: 助手历史不自动发送

- **WHEN** 学生点击最近的问题或清空提问历史
- **THEN** 点击只回填等待确认，清空只移除快捷记录，真实会话与消息保留
