# teacher-identity-and-permissions Specification

## Purpose

规定教师学科、任教班级与班主任班级的叠加身份及权限边界，班主任菜单按身份常驻，学生密码重置仅限本人带班班级。

## Implementation Status

2026-10-16：身份字段、菜单上下文、学生名单及重置密码已实现；学情诊断、教研及班级事务的业务接口仍需后续完成。班主任全科资料/作业/学情为班级总览权限设计，不代表所有跨学科后端能力均已实现。

## Requirements

### Requirement: 教师学科身份

系统 MUST 为每位教师账号记录学科（subject，如 math / english）。教师工作空间 MUST 展示其学科教研组身份；有带班班级时 `/teacher` 默认进入本班首页，否则进入本学科教研入口。JWT Payload MUST 携带学科身份，后端对教研资料的访问控制 MUST 以 Token 中的学科为准，MUST NOT 信任请求参数。学生账号 MUST NOT 拥有学科身份。

#### Scenario: 教师登录进入本学科教研组

- **WHEN** 学科为 math 的教师登录系统
- **THEN** 系统展示数学教研组身份和本学科教研入口；若有班主任班级，默认本班首页同时提供班主任与任课菜单

#### Scenario: 教师学科身份随 JWT 生效

- **WHEN** 学科为 english 的教师调用教研资料接口，请求体中未声明学科
- **THEN** 系统从 JWT Payload 读取 subject=english 进行权限判定，返回英语学科教研资料

### Requirement: 教研资料按学科隔离

教研资料（智能备课、智能命题、教研问答、课例分析）MUST 严格按学科隔离。教师 MUST 只能访问本学科教研组内的资料。班主任身份 MUST NOT 突破学科壁垒：即便某教师是某班班主任，跨学科访问教研资料 MUST 返回 404（隐藏存在性）或 403 并记录审计日志。

#### Scenario: 数学教师访问数学教研资料成功

- **WHEN** 数学老师张老师访问数学课标或数学讲义
- **THEN** 系统校验 subject=math，正常返回数学教研资料

#### Scenario: 数学班主任跨学科访问英语资料被拒

- **WHEN** 数学老师张老师（同时是一班班主任）尝试访问英语教研资料
- **THEN** 系统返回 404（或 403）并记录审计日志，班主任身份不赋予英语学科资料访问权

#### Scenario: 跨学科教研资料不可见

- **WHEN** 英语老师李老师打开教研资料列表
- **THEN** 列表仅包含英语学科条目，数学学科资料不出现

### Requirement: 班主任身份与跨学科本班学情特权

系统 MUST 为教师账号记录班主任班级（homeroom_class_id，可空）。班主任 MUST 拥有跨学科查看**本班**学情的特权：可查看本班所有学科的总体学情、成绩与薄弱点。任课老师（非班主任或非本班班主任）MUST 仅能查看其任教班级的本学科成绩与掌握度。班主任的学情特权 MUST 受班级边界限制：不得以班主任特权查看其他班级的全科学情；若同时任教该班，仍仅可按任课身份查看本人学科。

#### Scenario: 班主任查看本班全科学情

- **WHEN** 数学老师张老师（一班班主任）查看一班学生的总体学情
- **THEN** 系统返回一班所有学科（含英语、语文等）的成绩与掌握度概览

#### Scenario: 班主任查看其他班级学情被拒

- **WHEN** 数学老师张老师（一班班主任）尝试以班主任身份查看二班的全科学情
- **THEN** 系统拒绝访问并返回 403，班主任特权仅限本班

#### Scenario: 任课老师仅看本学科成绩

- **WHEN** 数学老师张老师（非二班班主任）查看二班学生成绩
- **THEN** 系统仅返回二班学生的数学成绩，不返回其他学科成绩

### Requirement: 班级管理边界

班级管理（学生名单、日常事务）MUST 按班级边界控制：班主任可见本班全部学生名单与日常事务；任课老师仅可见其任教班级的学生名单。教师 MUST NOT 访问非任教班级的学生名单。

#### Scenario: 班主任可见本班全部学生

- **WHEN** 一班班主任张老师打开学生名单
- **THEN** 系统返回一班的全部学生名单

#### Scenario: 任课老师仅见任教班级名单

- **WHEN** 数学老师张老师（任教一班、二班）打开学生名单
- **THEN** 系统返回一班与二班的学生名单，不包含其他班级

### Requirement: 双重身份权限判定规则

系统 MUST 对不同功能模块采用不同的身份权重判定：教研资料访问只认学科身份（班主任身份权重为 0）；学情诊断综合学科身份、班主任身份与班级归属；名单读取按任教范围放行，班主任事务及学生密码重置仅按本人带班范围放行。三种判定 MUST 在接口层统一实现并覆盖所有教研相关端点，判定结果 MUST 可复算、可审计。

#### Scenario: 同一教师不同模块权限不同

- **WHEN** 数学老师张老师（一班班主任，任教一班二班数学）依次访问：英语备课资料、一班全科学情、二班英语学情
- **THEN** 访问英语备课资料被拒（404/403）；一班全科学情放行；二班英语学情被拒（非二班班主任且非英语老师）

### Requirement: 班主任身份不随工作区消失

系统 MUST 以 `homeroom_class_id != null` 推导班主任身份，不依赖当前 `workspace`。切换任课教学或任教班级 MUST NOT 隐藏已有的班主任菜单，也 MUST NOT 扩展班主任可操作的班级范围。

#### Scenario: 任课教学保留班主任模块

- **WHEN** 高二（1）班班主任张老师在高二（2）班任课教学中浏览
- **THEN** 班主任模块仍可见，点击本班学生进入 `workspace=homeroom` 且 `class_id=101` 的页面

### Requirement: 学生密码重置仅限本班班主任

系统 MUST 仅允许 `student.class_id == current.homeroom_class_id` 且学生已分配班级时重置密码。任课身份本身 MUST NOT 授予重置权限；接口 MUST 独立于前端菜单校验权限。

#### Scenario: 班主任重置本人带班学生密码

- **WHEN** 张老师重置班级 101 的李明账号
- **THEN** 后端按初始密码规则重置并设置 `must_change_password=true`

#### Scenario: 任课教师调用重置接口被拒

- **WHEN** 张老师尝试重置其任教的班级 102 的王芳账号
- **THEN** 返回 403，王芳的密码保持不变，即使张老师具有该班任课权限
