# Smart Lesson Preparation

## Purpose

2026-10-19：实现“选择组内教师资料 → AI 教师教案草稿 → 编辑／审阅／定稿 → 生成学生可见教案及配套学生讲义 → 核对后分班发布”。原资料发布流程继续可用。教师完整稿默认本人私有，定稿后可主动选择共享到本学科教研组；学生端接收去掉答案、教师解析及提示的独立文稿。

## Implementation Status

截至 2026-10-20：教师草稿生成、保存、章节重写、人工审阅、定稿版本/修订、两种学生稿生成编辑、核对后分别多班发布、完整教师定稿可选同科共享已实现。配图复用导入原图并校验指纹，兼容中文空格路径；使用浏览器打印/另存 PDF 和图文包下载。教师版 Word/PDF 直接解析、自动绘制新图、真实学情诊断、服务端 PDF/Word 导出、逐键自动保存尚未实现。验收依据见 changes/add-smart-lesson-prep/validation.md。

## Requirements

### Requirement: 从学科组教师资料发起备课

教师 MUST 在 /teacher/lesson-prep 选择 1–5 份本学科 ResearchMaterial、任教班级、课题及 10–180 分钟课时，选填教学范围、课标/目标、班级情况及额外要求。后端 MUST 使用当前数据库教师学科及任教关系，不接受客户端指定学科。页面 MUST 说明点击生成将向已配置 DeepSeek 发送所选资料片段和教学要求，配图仅提供路径，不发送图片本体。本期没有真实学情诊断接入，MUST NOT 将演示统计或未填写信息当作真实学情。

#### Scenario: 数学教师发起线面角备课

- **WHEN** 数学教师为本人任教班级选择组内教师资料、线面角范围及 45 分钟课时
- **THEN** 使用所选组内教师正文和明确教学要求生成教案，不使用其他学科或学生资料索引

#### Scenario: 尚未提供学情

- **WHEN** 教师没有填写班级情况
- **THEN** 不虚构班级统计、薄弱点或课标条目，可在草案注明待了解

### Requirement: 完整片段与出处核对

系统 MUST 从所选教师正文按 Markdown 章节提取完整片段，结合课题与范围排序，最多 16 个、合计不超过 45000 字符；每份所选资料至少提供一个完整小节，超量或缺少合适小节 MUST 提示调整而非截断公式/题目。每个片段 MUST 保存 S编号、原文件 ID、文件名、原文行号、完整摘录和 SHA-256。生成前和落库前 MUST 核对原文件版本。教师页面 MUST 展示这些真实依据并可直达对应原稿；未提供的引用编号 MUST 被拒绝。编号和指纹只能验证来源身份，MUST NOT 宣称自动证明语义支持，引用与例题计算仍须教师审阅。

#### Scenario: 核对例题出处

- **WHEN** 生成教案引用 [S1]
- **THEN** 教师可查看 S1 的真实原文、文件指纹和 Markdown 行号，并打开对应教师原稿，不伪造 Word/PDF 页码

#### Scenario: 多份资料均被选入

- **WHEN** 教师选中数份同科资料
- **THEN** 每份至少保留一个完整小节，超过上下文预算则明确要求减少资料或整理章节

### Requirement: 中文空格图片路径兼容

备课上下文、生成保存、教师编辑保存、章节重写、学生稿保存及班级发布 MUST 将相对图片路径规范为 URL 百分号编码，保持资源原名/指纹和鉴权不变，不重复编码已有地址。模型 MUST 被提示保留给定编码。预览 MUST 兼容旧教案中含未转义空格的图片地址，使其通过原有鉴权图片组件显示；MUST NOT 为修复预览而改写已有正文、定稿历史或重新调用 AI。代码示例中的图片写法不随显示兼容处理而变化。

#### Scenario: 原题图的中文目录含空格

- **WHEN** 教案已保存图片路径 sources/1/第一章 空间立体几何.assets/ex01-original.png
- **THEN** 预览正确加载授权原图，不再将图片标记显示为文字，已有教案内容与修订号保留

#### Scenario: 生成与发布图文包

- **WHEN** 模型返回含空格的相对图片地址并保存学生稿、发布到班级
- **THEN** 正文中的图片目的地址被编码，配图仍按原名及 SHA 匹配，图文包保留原图片文件名和有效的相对链接

### Requirement: 流式生成与失败处理

教案生成 MUST 复用现有 DeepSeek stream_chat，输出教学目标、重难点、准备、教学过程及时间安排、例题与教师解答、练习、课后任务和板书设计。教师稿 MUST 标明教学设计补充与原稿引用的区别。成功完成才创建 draft 教案；半篇输出、无效引用、异常图片路径或不完整结构 MUST NOT 作为完成草案保存。未配 Key 返回 503；生成失败/超时通过 SSE 错误帧明确提示，表单保留，不伪装成离线 AI 结果。前端无 done 帧 MUST 按中断处理。单教师同时只允许一个生成任务，完成/失败/取消后释放。

#### Scenario: AI 完成教师草案

- **WHEN** 模型完整输出并通过结构及来源检查
- **THEN** 保存草稿、当前修订号及来源快照，页面可编辑，不自动发布

#### Scenario: 生成中断或无 Key

- **WHEN** 连接中断、模型出错、超时或服务未配置
- **THEN** 显示明确错误，保留教学要求及已有稿，不把半篇输出标记为已保存或已定稿

### Requirement: 编辑审阅与章节重写

教师 MUST 可编辑并显式保存草稿。编辑已审阅稿或重写章节 MUST 回到 draft、失效审阅。章节重写 MUST 要求已保存当前修改、按唯一二级标题定位，只替换所选章节；模型输出其他标题/整篇教案时 MUST 拒绝且保留原稿。教师确认核对正文、公式、例题与引用后可标记 reviewed，未经审阅不得定稿。

#### Scenario: 重写教学过程

- **WHEN** 教师选择现稿唯一的教学过程二级标题并要求增加讨论
- **THEN** 只替换该章节，其余正文保持原样，保存为待重新审阅的草稿

#### Scenario: 审阅后再改正文

- **WHEN** 教师保存对 reviewed 教案的修改
- **THEN** 状态回到 draft，必须重新确认审阅

### Requirement: 定稿快照与并发保护

reviewed 教案 MUST 可定稿为 final 并递增定稿版本、保存不可变内容和来源快照。final 正文只读，继续修改 MUST 显式开始新修订，旧定稿及班级已发布资料保留，学生草稿失效。历史展示为定稿快照，不宣称每次键入都保留编辑历史。所有写操作 MUST 携带 revision 并执行数据库乐观锁；旧窗口或生成期间被更新的版本 MUST 拒绝覆盖。

#### Scenario: 第二次定稿

- **WHEN** 教师将 v1 开始新修订、修改、审阅后再次定稿
- **THEN** 保存 v2，v1 可回看，新稿须重新生成学生版本

#### Scenario: 旧窗口写入

- **WHEN** 请求 revision 落后于数据库当前值
- **THEN** 返回 409 或生成错误帧，不覆盖新稿，页面提示重新加载

### Requirement: 从定稿生成两种学生稿

系统 MUST 从当前 final 教案和对应原始资料生成 student_lesson（学生可见教案）及 student_handout（配套学生讲义），独立保存并绑定定稿版本。学生可见教案保留目标、知识框架及课堂活动；讲义包含选用题干、知识点及作答空间。两份 MUST 提示去掉题目答案、教师解析与提示，不得带教师私有引用/链接或未选入配图。后端 MUST 拒绝明显答案标记、HTML、外部链接及错误图片路径；普通数学不等式不得误判 HTML。本期为提示词与显式标记检查，MUST NOT 承诺通用答案/图片语义检测，发布前必须人工核对。生成失败保留旧学生稿，修改后核对状态失效。

#### Scenario: 教师生成并修改学生讲义

- **WHEN** 当前教案已定稿，生成两份学生稿并修改其中一份
- **THEN** 可独立预览两稿并保存；重新核对前不能发布，教师完整稿及来源不受影响

#### Scenario: 学生稿生成未通过检查

- **WHEN** 模型返回无效 JSON、明显解答标记或未授权图片
- **THEN** 提示重试，旧稿保持，不能保存或发布失败结果

### Requirement: 两种学生文稿分班发布

教师 MUST 能分别选择学生可见教案或学生讲义，核对当前文稿无答案和教师提示后选择任教班级发布。后端 MUST 从已保存当前学生稿取正文，不接受客户端任意正文作为发布内容；重新校验归属、学科、所有目标班级、revision、定稿绑定、正文及所有图片指纹。任一目标越权则整批拒绝。每班独立创建 Material、仅复制正文实际使用的原图并索引学生内容，记录教案定稿版本与正文 SHA；相同版本/类型/班级/内容重复提交 MUST 复用旧发布，不重复建资料。教师原稿、教师完整教案及未使用解析图 MUST NOT 自动进入学生资料。

#### Scenario: 教案和讲义均发布给学生

- **WHEN** 教师分别确认两种学生稿并发布到所选任教班级
- **THEN** 班级资料中出现两个独立学生文稿，保留预览与下载、图文包及浏览器另存 PDF 功能

#### Scenario: 发布批次混入其他班

- **WHEN** 目标班级中包含非当前任教班级
- **THEN** 返回 403，整批不创建任何班级资料

#### Scenario: 新修订尝试发布旧学生稿

- **WHEN** 教案已经开始新修订或新定稿尚未重新生成学生稿
- **THEN** 返回 409，不发布旧版本学生稿

### Requirement: 教案隔离删除与审计

教师教案、版本、学生草稿及私有原图接口 MUST 校验当前数据库身份、本学科、教案所属任教班级和本人归属，学生、跨科、其他教师或已撤销任教关系均不可读取。列表 MUST 仅含当前有权限的本人教案。写操作记录审计；普通 403 由已有中间件审计。删除私人教案 MUST 清理定稿快照和教案发布关系，但保留已独立发布的班级资料及教研组共享稿，共享关系解除私人教案关联；删除班级资料 MUST 清理其教案发布关系和配图，保留私人教案与组内原稿。

#### Scenario: 同学科同事访问私人教案

- **WHEN** 同学科另一教师尝试读取不属于自己的教案或配图
- **THEN** 返回 403，即使可以共享原始教研资料也不可读他人私人教案

#### Scenario: 删除私人教案

- **WHEN** 所属教师确认删除教案
- **THEN** 删除后读取 404，定稿快照清理，班级已发布文稿及教研组共享稿仍能独立访问

### Requirement: 教师定稿可选共享到教研组

完整教师教案 MUST 默认私有，生成、审阅、定稿均 MUST NOT 自动共享。作者可在当前 final 状态、无未保存修改时，主动将当前定稿发布到本学科教研组。请求 MUST 校验本人、当前学科及任教关系、revision 和定稿快照一致性；草稿、未审阅稿及过期修订 MUST 返回 409。共享 MUST 创建独立 ResearchMaterial/ResearchChunk，保存完整教师正文、仅正文使用的配图、文件/图片 SHA 及原始出处摘录快照，MUST NOT 创建班级 Material 或学生索引。

#### Scenario: 教师选择保留私有

- **WHEN** 教师生成并完成定稿，没有点击发布到教研组
- **THEN** 同科同事仍不能读取私人教案，组内列表不新增共享稿

#### Scenario: 主动共享完整教师定稿

- **WHEN** 作者点击发布当前定稿到教研组
- **THEN** 本学科教师可在共享教案中读取独立正文、答案、原图及出处；跨科和学生访问正文、配图及图文包返回 403，私人原教案仍仅作者可编辑

#### Scenario: 重复发布或后续修改

- **WHEN** 同一定稿重复共享，或作者开始新修订并再次定稿
- **THEN** 同一定稿复用原共享记录；私人新修改不改变旧共享稿，新定稿需再次主动共享才新增组内版本

#### Scenario: 删除私人原教案

- **WHEN** 作者删除已共享过的私人教案
- **THEN** 组内共享稿和已复制原图仍独立可用，并保留原始出处记录
