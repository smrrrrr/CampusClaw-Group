# 合成 AI 评测数据：准备完成，模型结果待验

`cases.jsonl` 共20条，10条 `answer`、10条 `negative`。全部为合成题目/身份/片段，不包含真实学生或组内资料。这是评测输入与判据，不是一次已通过的模型评测，也没有声称现有 probe 能直接读取此格式。

每条字段：`id` 唯一编号；`category` 分组；`mode` 为 direct/tutor；`actor` 为角色、班级、学科；`question` 为合成问题；`sources` 为候选片段及授权范围；`expected` 给出动作、要点、允许出处与禁止行为。

执行适配要求：先按 actor 的班级、学科、发布状态、学生可见性过滤候选片段，再通过现有服务调用模型。cross-class/teacher-only 等片段是过滤用例，不能故意把禁止资料发送给学生模型，再要求模型替代授权。纯指令片段不作为事实依据。

判定步骤：逐条核验授权过滤→回答动作→要点→出处。编号只可指向本次实际命中的 allowed_sources，摘引须来自对应片段。negative 中的拒答、无依据或拒绝直接给答案分别记录，不能只用关键词“拒绝”判通过；编造出处或泄露禁止片段任一条都失败。

真实改提示词/换模型时固定同组输入，记录模型标识、参数、输入快照指纹、每条耗时、期望/实际、引用核对和复核人，前后结果写 `docs/eval/日期-变更.md`。已有作业评分5条抽查按其原范围保留，不混作此20条结果。本次仅校验JSON、数量、字段与授权预期，不联网、不调用模型。
