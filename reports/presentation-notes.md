## 五分钟问答准备

| 可能的问题 | 先回答怎么验证，再回答实现 |
| --- | --- |
| 为什么20并发不会重复评分？ | C1断言同任务且评分时间不变；实现是版本唯一键、租约与条件写回。外部模型调用仍可能重试。 |
| 写入一半失败怎么办？ | B3在第二条插入注入异常，503并整批回滚；任务与发件箱在同一短事务内提交。 |
| 404怎么证明不是资源不存在？ | 同编号先用有权账号下载200，再换他班账号404，且无正文。 |
| 为什么学生提交不是202？ | 当前合同由教师触发初批才创建后台任务；学生只保存答案返回200，真实端点见 backend/routers/homework.py。 |
| 安全门禁绿是否等于无漏洞？ | 不是。原始OS告警保留，门禁按明确的包/版本/期限/镜像缓解判据执行，CRITICAL不豁免。 |
| AI自己审核可靠吗？ | 先用已知坏输入证明脚本能红，再修复复跑绿，且保留人的Review；不把AI口头结论当证据。 |
| 为什么报告写待部署？ | 当前外部地址未提供，本机与CI不是课堂外部环境；收到地址后按四步留实际证据再更新报告。 |

证据里找不到的数字直接说明“尚未验证”，记录后补，不以示例中的性能数字或路径作答。
