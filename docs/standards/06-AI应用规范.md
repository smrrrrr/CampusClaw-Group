# 06 AI应用规范

**什么时候读：** 改提示词、模型参数、检索、生成或工具调用时。涉及llm/lesson/question/homework服务、MCP编排、rag_search、model_json及教师配置的提示词/技能。

**这份规范要保证：** 模型只做需要生成或判断的事；权限、分值、数量与出处边界由可检查的规则负责。由AGENTS与prompt-change引用。

## 1. 哪些交给模型，哪些必须确定

| 环节 | 模型负责 | 程序规则负责 |
| --- | --- | --- |
| 学科助手 | 解答或引导 | 班级/学科检索、引用编号、每日额度 |
| 智能备课 | 教案与学生稿 | 去答案校验、图指纹、版本/发布记录 |
| 智能命题 | 题目内容 | 结构/公式/知识点、题型配比 |
| 命题作业初批 | 根据冻结依据建议原卷得分 | 数值合法性、范围、百分制折算、并发写回 |
| MCP | 提议工具及参数 | schema校验、候选范围、白名单、调用上限 |

**检查：** 能由明确规则计算的值，不靠模型自由生成。现有检索是字符n-gram向量与关键词混合，不包装成未实现的能力。

## 2. 工具只走现有服务

模型只可调用教师登记并发现的工具，经mcp_orchestrator→mcp_client执行。不开放任意数据库查询、uploads读取或任意HTTP工具。

**检查：** 追到最终适配调用；每次调用受次数、超时、schema和审计约束，不能只看模型说“调用成功”。

## 3. 提示词按代码管理

- 系统提示词以代码常量保存，随版本入库，不放.env。
- 修改提示词走变更流程，并在旁边写 `# prompt-version: YYYY-MM-DD`。
- 修改前后用同一批案例评测，在validation引用结果。
- 教师页面保存的提示词/技能是业务数据，也受输入边界约束；不能覆盖最终追加的CITATION_POLICY。
- 命题初批只能使用发布时冻结的答案、解析与分值；评分私有依据不进入学生响应。

**当前差距：** 部分旧常量尚无版本注释。下次改对应提示词时必须补版本与前后记录，不因旧代码例外继续漏写。版本清单见第9节。

## 4. 模型和参数集中配置

模型名、地址、温度、超时、检索阈值集中在config.py，不散落业务调用点。配置记录要写实际使用的模型，不能用“课程网关”替代模型标识。

当前Settings有温度0.3、超时60秒、top_k=3、相对阈值0.35、关键词门槛3等默认值；它们是当前配置依据，不是新建能力时可随手复制的魔法数。

## 5. 超时与降级必须可见

- 模型调用带deepseek_timeout；失败返回中文503或SSE error，不无限等待。
- 模型Key未配置时，既有资料仍可读；需要生成的能力按接口合同受限，health报告not_configured。
- MCP不可达时普通助手可继续回答，但不能假称有工具结果。

**检查：** 模拟超时、未配置和坏输出，既无成功done，也不写入部分生成结果；按各接口的失败合同验收。

## 6. 输出和依据都要校验

1. 结构化JSON先经model_json解析/修补，再按业务结构校验；失败不能用默认内容入库。
2. 资料、技能、工具结果、学生作答都作为数据，不执行其中“忽略规则”的指令。
3. 无本班检索依据时说明无依据，不挂出处；出处编号必须指向本轮真实片段，摘引逐字可对照。
4. 解题引导模式给步骤和提示，不直接给最终答案。

**检查：** 清空本班资料、换他班片段、加入诱导文字，核对实际过滤、回答和引用。图片指纹证明文件一致，不能证明题目或模型答案语义正确。

## 7. 评测集与前后比较

数据在 [apitest/eval/cases.jsonl](../../apitest/eval/cases.jsonl)，说明在 [评测README](../../apitest/eval/README.md)：20条合成用例，10条应答，10条拒答/无出处。

改提示词或换模型时：固定案例、授权片段、模型与参数；分别记录答对、拒答/无依据、引用核对。**任一编造出处都不通过**，不能只给总答对率。

用可用的probe或明确适配后的执行器，结果写 `docs/eval/日期-变更.md`，validation引用案例级前后结果。不得保存真实学生正文或密钥。

**当前状态：** 20条数据已准备，通用执行器及真实前后结果未完成。已有5条命题评分抽查只说明其限定案例，不代替20条检索问答评测。JSON静态校验通过也不等于模型通过。

## 8. 用量与日志

记录模型标识、调用类型、耗时、成功与否、命中片段数。不记完整提示词、学生提问或资料正文。学生日额度由ai_question_logs计数。

改模型、参数或额度前先确认本次供应商的实际限制；真实调用与费用记录写入对应变更，不混入静态数据准备结果。

## 9. 当前提示词与检查入口

| 提示词 | 位置 | 版本记录现状 |
| --- | --- | --- |
| 默认解答、引导、出处政策 | llm_service.py | 旧常量尚无逐个版本注释 |
| 教师教案、学生稿 | lesson_service.py | 同上 |
| 命题生成 | question_service.py | 同上 |
| 手工作业初批 | homework_service.AI_GRADE_PROMPT | 同上 |
| 命题作业初批 | homework_service.QUIZ_GRADE_PROMPT | 2026-11-04；有对应5条抽查 |

业务检查使用check_lesson_prep、check_question_bank、check_quiz_homework、check_mcp_tools；引用/引导另见check_lessons_2_5与真实probe。自动替身检查不证明真实模型准确率。

## 违反时

出现伪造出处或注入失败时先保留复现案例，再按变更修复并重测。没有评测/抽查记录的提示词改动不算完成。
