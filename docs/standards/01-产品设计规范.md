# 01 产品设计规范 · CampusClaw

适用：`frontend/app/**`（页面）、`frontend/components/**`（组件）、界面文案。
被谁读到：`AGENTS.md` 规范索引（改 `frontend/` 时必读）；技能 `add-endpoint`（涉及页面时）。

## 1. 用户与场景

| 角色 | 场景 | 落到的页面 |
| --- | --- | --- |
| 教师 | 导入教研组资料、核对学生版并发布到班级 | `/teacher/library`、`/teacher/upload` |
| 教师 | 生成、编辑、定稿教案与学生讲义 | `/teacher/lesson-prep` |
| 教师 | 出题、复核、组卷、发布试卷 | `/teacher/quiz` |
| 教师 | 配置本学科班级助手、技能、MCP 工具；班主任管学生名单与审计 | `/teacher` |
| 学生 | 向学科助手提问、核对出处、回看会话 | `/student` |
| 学生 | 浏览、下载、打印本班已发布资料 | `/materials` |
| 全部 | 登录、首次改密、无权限提示 | `/login`、`/change-password`、`/403` |

每条规约中的场景都必须落到上表某个页面；落不到的先回去改规约，再加页面。
判据：新增页面的 PR 同时修改本表；本表里每个路由在 `frontend/app/` 下都有对应 `page.tsx`。

## 2. 术语表：一个概念只有一个词

| 界面用词 | 接口 / 代码 | 禁止混用 |
| --- | --- | --- |
| 资料 | material（班级资料）、research_material（教研组资料） | 文档、文件（“文件”只指上传的附件本身） |
| 教研组资料 | research_materials | 组内资料、公共资料 |
| 教案 | lesson_plan | 课件、备课稿 |
| 讲义 | handout（学生版资料） | 学案、练习纸 |
| 学生版 | student copy / student draft | 学生稿（只在代码与规约中使用） |
| 出处 | citation，正文中写作 [n] | 引用来源、参考链接 |
| 题库 / 试卷 | question bank / paper | 题集、卷子 |
| 学科助手 | agent / assistant | 机器人、AI 老师 |
| 会话 | conversation | 对话（书面材料中不写“对话”） |

同一屏出现同一概念的两种叫法即为缺陷。接口字段名以规约为准，本表只约束界面用词。

## 3. 视图状态必须枚举完

每个数据视图都要有四种形态，统一文案模板：

| 形态 | 文案模板 | 现有写法 |
| --- | --- | --- |
| 加载中 | `加载中…` | 已统一（16 处） |
| 正常 | — | — |
| 错误 | `加载失败：<可理解原因>`，并给出“重试”或下一步 | 有 `加载失败`、`加载失败，请重试。` 两种，新代码用模板 |
| 空状态 | `暂无<对象>` + 下一步动作（如“点击「新对话」开始”） | 已基本统一 |

本项目特有的第五种形态：**助手检索无命中**。不显示空白，也不挂出处编号，回答中说明“未在本班资料中找到依据”。
判据：任取一个列表视图，断网、清空数据、正常三种情况各看一次，三种文案都按模板出现。

## 4. 表单与校验时机

- 上传：选择文件即校验扩展名与大小（`ALLOWED_EXTENSIONS`、`MAX_FILE_SIZE_MB=50`），提交时再由服务端校验；前端校验不替代服务端校验。
- 改密：提交时校验密码策略，错误信息逐条列出不满足的规则。
- 提问：提交时校验非空；发送后输入框禁用，直到流式回答结束。
- 教师入口只在会话角色为 teacher 时渲染；隐藏入口不是授权手段，服务端仍会拒绝。

## 5. 视觉基线按令牌写

- 颜色只用 `frontend/app/globals.css` 中 `:root` 的令牌：`--brand`、`--brand-hover`、`--brand-soft`、`--canvas`、`--surface`、`--ink`、`--ink-2`、`--ink-3`、`--line`、`--line-strong`、`--success`。新增语义色（警告、错误）先加令牌再使用。
- 间距刻度：4 / 8 / 12 / 16 / 24 / 32 px；字号层级：正文 14–15px、小标题 16px、页面标题 22px。
- 组件先复用 `frontend/components/`（`app-layout`、`markdown-answer`、`material-preview`、`class-selector` 等），新页面不得自造同类组件。
- 模型输出与资料正文一律经 `markdown-answer`（react-markdown + KaTeX）渲染，不用 `dangerouslySetInnerHTML`。

判据：`grep -rn "#[0-9a-fA-F]\{6\}" frontend/app frontend/components` 的新增命中只能出现在 `:root` 令牌定义里。

## 6. 可达性与响应式下限

键盘能走完“登录 → 进入学科助手 → 提问 → 查看出处”；所有表单控件有关联标签；断点两档（窄屏单列、宽屏侧栏）。

## 违反时

先判断是页面清单 / 术语表没同步，还是实现偏离：前者两处一起改并写进变更说明，后者改代码。
