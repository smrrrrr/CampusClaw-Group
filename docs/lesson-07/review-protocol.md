本文件是可执行步骤，未填写的执行结果不得视为已完成；不让当前有历史上下文的代理冒充另一个会话或另一名组员。

## 无历史上下文会话

由操作者明确新建空白会话，只提供仓库绝对路径与变更名。验证者先说明实际读取到的 AGENTS、规范索引、技能路径和变更四类材料；仅文档变更应识别 skip_specs，不编造业务 Scenario。给出能力/条款→Scenario或文档检查→命令与预期信号的映射，指出缺失输入，而不是依靠口头背景补全。

自动加载要分工具记录：Codex 是否收到 AGENTS；Claude 是否导入 AGENTS；Trae 是否识别 description/alwaysApply。看见文件存在不等于自动加载成功。若做代码生成验证，在独立分支/临时目录选一项已授权任务，不触真实数据，核对分层、命名、失败路径及完整门禁；未经用户授权不自动 apply、归档或改任务勾选。

记录：执行人、时间、工具/版本、只给出的两项输入、实际读取路径、可否独立复现、卡点、检查名及输出摘要。本轮未创建新会话，状态为待验证。

## 另一名成员在另一机器启动

1. 组长确认教师仓库访问权限、成员已加入及主干保护，记录设置证据；不在文档写令牌。
2. 验证者在自己的新目录按 README→DEPLOYMENT 执行，选择空库或新目录数据包恢复。没有文档写出的步骤视为卡点，不凭经验补后写“顺利通过”。
3. 按 `.claude/skills/fresh-start/SKILL.md` 配置 `.env`、检查 Compose、启动、免认证 /health 与登录页；模型可选状态单列。
4. 记录 clone 提交、系统、每步耗时、实际端口、依赖状态、门禁、遇到的问题和文档修订。用备份副本演练恢复/回滚，不重置已有真实账号。
5. 将本人结论和证据提交到 docs/lesson-07；当前实施者只核验材料，不代签另一人或声称教师已批准。
